# ФИКСТУРА (tools/fixtures/no-docs-dir/) — замороженный снимок

Снимок состояния, которое guard `tools/check-no-docs-dir.sh` обязан отвергнуть:
в корне репозитория (или в проверяемом каталоге) присутствует каталог `docs/`.

Файл НЕ является проектной документацией: его читает только guard-скрипт, который
прогоняет против него сценарий «каталог `docs/` запрещён»
(FR-012, FR-001, SC-005, ADR-0011).

Ожидаемый результат прогона:

```bash
bash tools/check-no-docs-dir.sh --root tools/fixtures/no-docs-dir/vulnerable
# код возврата: 1 (нарушение найдено)
```

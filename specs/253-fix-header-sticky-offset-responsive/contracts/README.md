# Contracts: 253 — sticky-блок приклеивается к AppHeader на узких экранах

**Branch**: `253-fix-header-sticky-offset-responsive` | **Date**: 2026-08-27

## Резюме

Изменение не вводит и не модифицирует **никаких внешних контрактов**:

- Не добавляет REST-endpoint.
- Не меняет формат стрима `meta`/`song`/`done` для `/api/public/zakroma`.
- Не меняет DTO `ZakromaPublicDto` / `AlbumTypeSummaryDto`.
- Не меняет схему БД, sync-флаги, миграции.
- Не меняет Vuex-стейт, composables.
- Не публикует и не потребляет JSON-схемы, CLI-аргументы, публичные API.
- НЕ модифицирует публичный API Vue-компонента `AppHeader.vue` (scoped CSS остаётся scoped; никаких изменений в props / events / slots).

## Что НЕ является внешним контрактом

- **CSS-переменная `--km-header-height`** — observable для других view
  (SearchView, AccountView и т.п.), но это **декларативная** часть design-system,
  не API и не интерфейс. Если значение меняется — это ломает только sticky-offset
  в **этом** компоненте, не другие компоненты (другие view могут использовать
  или не использовать эту переменную по своему усмотрению).

- **DOM-структура `<div class="km-author-header-sticky">`** — приватная разметка
  Vue view; внешними селекторами не используется. Изменение `top`-значения
  этого класса не отражается ни на каких тестах / парсерах.

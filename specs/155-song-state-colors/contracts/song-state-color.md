# Contract: song-state-color

## Назначение

Зафиксировать значения цвета, которые backend передаёт административным представлениям песни.

## Поля представления

- `SongDTO.color` — цвет состояния полной записи песни.
- `SongDTOdigest.color` — цвет состояния облегчённой записи песни.
- `PublicationDTO.publish10..publish23.color` — тот же цвет во вложенных песнях сетки публикаций.

## Допустимые значения

| Состояние | Значение `color` |
|---|---|
| `DONE` | `#CCFFCC` |
| `TODAY` | `#FFFF00` |
| `ON_AIR` | `#33FF33` |
| `EXCLUSIVE` | `#99CCFF` |
| `IN_WORK` | пустая строка |

## Инварианты

1. Для одной песни все представления используют одинаковое значение цвета.
2. Пустая строка является допустимым результатом и означает отсутствие специальной окраски.
3. Цвета старых статусов площадок и старого fallback по `idStatus` не передаются как цвет состояния песни.
4. Контракт не добавляет отдельное поле состояния в DTO и не требует изменения формата хранения песни.

## Проверка

Проверить этот контракт на матрице из `data-model.md` и в таблице песен/сетке публикаций по шагам `quickstart.md`.

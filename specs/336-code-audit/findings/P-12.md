## Сверки

1. **BR-183 (P-15) подтверждается — новый BR не заводится.** `MltNode.toString()` собирает XML без экранирования атрибутов и тела (обещание KDoc не выполнено), и в порции P-12 это достижимо сразу по нескольким путям: `MltClasses.kt:203–207` отдаёт текстовое значение как `body` без обработки («return MltNode( / name = "content" / fields = fields / body = value / )»), а все шаблоны `kdenlivetitle` уходят в `xmldata` через `template().toString().xmldata()` — `MkoBoosty.kt:39`, `MkoBackChords.kt:39`, `MkoChordPictureFader.kt:49`. Экранирования на уровне writer'а нет: `Functions.kt:451` собирает `"<?xml version='1.0' encoding='utf-8'?>\n${getMlt(mltProp)}"`, `Functions.kt:470` пишет его `fileMlt.writeText(templateProject)`; `xmldata()` (`Extentions.kt:107`) заменяет только `<`. То есть отдельного «другого пути с экранированием у писателя» не существует — механизм один и тот же, BR-183 его и описывает. **Уточнение к радиусу:** в вызывающем коде уже стоит ручное экранирование в двух разных конвенциях — одиночное `&amp;` для атрибутов самой `.mlt` (`Song.kt:3045`, `:3093`, `:3177–3181`) и двойное `&amp;amp;` для текста внутри `xmldata` (`Song.kt:3057–3069`, `SongVoiceLineElement.kt:100`, `SongVoiceLineElementSyllable.kt:172`, `MkoSongText.kt:94`, `MkoScroller.kt:169–171`; обратное преобразование — `UtilsPictures.kt:758`). Поэтому цифра «564 песни» (песни с `&` в названии/авторе/альбоме) — это оценка сверху: часть полей на этих путях уже экранируется точечно. Радиус стоит перемерить на фактическом `.mlt` (прогон рендера — `эмпирика: требует согласия`); на сам дефект это не влияет, а вот на severity/приоритет — может.
2. **Аккордный MLT-путь (`CHORDS`) в текущем коде не генерируется — поэтому четыре файла порции (`MkoBackChords`, `MkoChordBoard`, `MkoChordPictureElement`, `MkoChordPictureFader`) в находки не выведены.** `Song.createKaraoke(songVersion)` для `CHORDS` — пустой блок: «SongVersion.CHORDS -> {} // createKaraoke(createLyrics = false, createKaraoke = false, createChords = true, createMelody = false)» (`Song.kt:6303`), вызовов `createKaraoke(createChords = true)` в репозитории нет, а `getMltProp` вызывается только из `Functions.createKaraoke` (`Functions.kt:449`).

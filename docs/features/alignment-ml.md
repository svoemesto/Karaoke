## Что делает

`alignment-ml/` — отдельный от Gradle Python-сервис forced alignment: по известному
тексту песни и вокальному стему расставляет тайминг каждого слога. Состоит из
HTTP-сервиса (`serve.py`, `POST /align`, `GET /health`), пайплайна обучения CTC-модели
(`train.py`, `chunking.py`) и оценки качества (`evaluate.py`). Вызывается из
`karaoke-app` через `AlignmentServiceClient.kt` (кнопка «Точные маркеры»).

## Зачем

Whisper не знает текст заранее и ошибается в таймкодах; forced alignment выравнивает
уже известный текст по аудио на CTC-модели. Аудит #336 (порция P-69) нашёл в сервисе
и пайплайне три S2-дефекта: блокировку event loop синхронным выравниванием, приём
файла без ограничений размера/длительности и тихое переиспользование словаря
CTC-головы от смоук-прогона.

## Как работает

### HTTP-сервис (`serve.py`)

- `POST /align` — multipart: `file` (аудио), `text`, необязательный `use_finetuned`.
  Ответ `{ok, syllables, used_finetuned}`.
- Обработчик **синхронный** (`def`): Starlette исполняет его в threadpool, поэтому
  `GET /health` отвечает во время выравнивания (BR-489).
- Приём ограничен: `ALIGN_MAX_UPLOAD_MB` (по умолчанию 64 МиБ) проверяется по
  `Content-Length` ещё до разбора multipart и повторно по числу реально прочитанных
  байт; тело копируется потоково (`_spool_upload`), а не `await file.read()` целиком
  в память (BR-490).
- Длительность проверяется по заголовку контейнера (`soundfile.info`) **до**
  декодирования: `ALIGN_MAX_AUDIO_SECONDS` (по умолчанию 600 с). Нечитаемый файл —
  `415`, превышение размера/длительности — `413` (BR-490).

### Пайплайн обучения (`train.py`)

- «vocab.json» (словарь символов CTC-головы) пишется вместе с «vocab.meta.json» —
  отпечатком sha256 состава обучающих чанков (файлы, интервалы, тексты), числом
  песен и чанков.
- Решение «использовать существующий словарь или перестроить» принимает
  `train.resolve_vocab()`: совпал отпечаток — переиспользование; не совпал и рядом
  нет чекпоинтов — перестройка; не совпал, но чекпоинты есть — `SystemExit`
  (перестройка сломала бы CTC-голову сохранённых весов); словарь без метаданных —
  перестройка без чекпоинтов либо «переиспользование без проверки» с предупреждением
  при наличии чекпоинтов (BR-491).
- Запись «vocab.json»/«vocab.meta.json» — только после CTC-фильтра и проверки
  «остались пригодные чанки», атомарно (`os.replace`).

## Инварианты

- Ответ `/align` без `ok: true` невозможен при отказе приёма: отказы — `400/413/415`,
  выравнивание для отвергнутого файла не запускается.
- `GET /health` не зависит от идущего выравнивания (event loop не блокируется).
- Пределы приёма настраиваются только переменными окружения, менять код для этого
  не нужно.
- Словарь CTC-головы соответствует составу данных, на котором учится модель, либо
  прогон останавливается до обучения (`SystemExit`), а не портит модель `[UNK]`.
- `--resume` не ломается: при наличии чекпоинтов словарь не перестраивается.

## Известные ловушки

- **`async def`-обработчик + синхронная тяжёлая функция = зависший сервис.**
  Starlette исполняет `async def` в event loop, поэтому `align_syllables` и ленивая
  загрузка 1B-модели блокировали и `/health`, и остальные запросы. Не возвращать
  `/align` к `async def` без `run_in_threadpool`.
- **`await file.read()` внутри обработчика.** Даже у синхронного обработчика
  `UploadFile.read()` недоступен; тело читается из `UploadFile.file` потоково.
  Вернуть `read()` — значит снова держать в RAM второй экземпляр файла.
- **`Content-Length` может врать или отсутствовать** (chunked). Проверка по
  заголовку — только первый барьер; второй (счётчик байт в `_spool_upload`)
  обязателен.
- **`soundfile.info` не декодирует PCM** — именно поэтому длительность проверяется
  по заголовку. Заменять его на `sf.read` для проверки нельзя: это ровно тот OOM,
  от которого защищает BR-490.
- **Смоук-прогон `train.py --limit N` пишет «vocab.json» в тот же `--output-dir`.**
  С «vocab.meta.json» полный прогон увидит несовпадение и перестроит словарь; при
  наличии чекпоинтов рядом — остановится. Для смоук-прогонов по-прежнему
  рекомендуется отдельный `--output-dir`.
- **Чекпоинты и словарь неразделимы.** CTC-голова зашита под `vocab_size`/индексы
  символов: удалять/перестраивать «vocab.json» при живых `checkpoint-*` нельзя —
  модель не загрузится или будет учиться на чужих индексах.
- **Порт 8017 не проксируется nginx и не имеет аутентификации.** Периметр —
  LAN админской машины (ADR-0004). Если сервис окажется доступен из публичной сети,
  пределы приёма — не замена авторизации (вопрос за владельцем).

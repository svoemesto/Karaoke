## 5. Что осталось за владельцем

1. **Seed-данные для стенда (часть BR-625).** Набор больше не зависит от
   *содержимого* песни, но для прогона на чужом стенде нужна **тестовая песня**
   с маркерами (и, для BR-619, с нотами). Создание тестовой песни через API/SQL
   — это запись в БД, а по брифингу БД и контейнеры трогать нельзя. Сделано всё,
   чтобы набор заработал на стенде с подготовленной песней: id задаётся
   `E2E_SONG_ID`, адрес — `E2E_BASE_URL`.
2. **CI-джоб e2e (P-68-01 = BR-507/BR-525, чужие задачи).** Набор теперь
   пригоден к запуску в CI (параллельный, без ретраев, без привязки к данным),
   но сам джоб требует стенда в CI — это отдельная задача (P-68-01 в карточке
   оставлена `TODO` намеренно).
3. **Порог задержки ввода.** «Бюджет 16 мс» из
   `knowledge/system/frontend/subs-edit-admin-editor.md` по-прежнему не
   достигается (замер: p50 обработчика ≈ 195 мс, до отрисовки ≈ 248 мс).
   Порог в измерялку **намеренно не зашит**: решение по нему принимает владелец.

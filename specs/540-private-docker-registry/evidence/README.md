# Доказательная база решений (issue #286)

Артефакты разведки и замеров на стенде. Здесь они лежат как **источники**
утверждений из [`../research.md`](../research.md) и [`../spec.md`](../spec.md) —
чтобы через полгода можно было проверить, откуда взялись числа и решения.

| Файл | Что доказывает |
|---|---|
| `research-registry-software.md` | выбор Zot: сравнение вариантов, инвентарь, исходники |
| `research-cert-renewal.md` | состояние сертификата, порядок ручного продления (FR-016) |
| `stand/RESULTS.md` | замеры стенда: RSS 49.9 → 114.3 МиБ, сохранение upstream-путей pull-through |
| `stand/config.json` | рабочий конфиг Zot стенда (с `content: [{"prefix": "library/**"}]`) |
| `stand/config-blanket-ondemand.json` | **провальный** конфиг: `onDemand` без `content` → 503. Оставлен как контрпример |
| `stand/rss-pull.txt`, `stand/rss-push.txt` | сырые замеры `docker stats` (покой и пик при публикации) |

## Что сюда сознательно НЕ попало

- `stand/htpasswd` — рабочие учётные данные стенда;
- `stand/docker-config/config.json` — содержит `auths` (токен доступа к стенду).

Оба файла остаются только на машине разработчика. Если понадобится воспроизвести
стенд — учётные данные генерируются заново (`registry/htpasswd.example`).

## TL;DR

Блок «последние 5 новостей» **переиспользует** существующий публичный эндпоинт `GET /api/public/news` (без изменений в бэкенде). Никаких новых контроллеров, DTO, SQL или миграций.

Этот документ фиксирует **как** существующий эндпоинт используется блоком на главной (параметры запроса, формат ответа, поведение при пустом/ошибочном ответе), а не проектирует новый контракт.

## Эндпоинт

`GET /api/public/news`

**Контроллер**: `karaoke-web/src/main/kotlin/com/svoemesto/karaokeweb/controllers/PublicNewsController.kt:30` (`PublicNewsController.list()`).

**Параметры запроса**:

| Параметр | Тип | Default | Описание |
|---|---|---|---|
| `page` | `Int` | `0` | Номер страницы (0-based). Блок на главной всегда вызывает с `page=0`. |
| `size` | `Int` | `20` | Размер страницы. Блок на главной всегда вызывает с `size=5`. |

**Тело запроса**: нет (GET).

**Тело ответа** (200 OK, JSON):

```json
{
  "items": [
    {
      "id": 12345,
      "title": "Новая песня: Аквариум — Город Золотой",
      "body": "...",
      "category": "air",
      "link": "/song?id=987",
      "publishAt": "2026-08-05 14:32:00.0",
      "createdAt": "2026-08-05 14:32:00.0",
      "published": true,
      "source": "auto"
    }
  ],
  "total": 19432,
  "hasMore": true
}
```

**Поля `items[i]`**:

| Поле | Тип | Используется блоком |
|---|---|---|
| `id` | `Long` | нет (нужен только как Vue `:key`) |
| `title` | `String` | **да** — текст колонки «Заголовок» |
| `body` | `String` | нет |
| `category` | `String` | нет |
| `link` | `String` (может быть `""` если NULL в БД) | **да** — `href` колонки «Ссылка»; **строка отбрасывается** если `""` |
| `publishAt` | `String` (Postgres `Timestamp` в виде строки) | **да** — строка парсится в `Date` для форматирования на фронте |
| `createdAt` | `String` | нет |
| `published` | `Boolean` | нет (всегда `true` для отданных новостей) |
| `source` | `String` (`"manual"` / `"auto"`) | нет |

**Заголовки ответа**: стандартные (`Content-Type: application/json`).

**HTTP коды**:
- `200 OK` — успех (в т.ч. с пустым `items`, если в БД нет опубликованных новостей).
- Любой другой HTTP-код (5xx, 4xx) — фронт трактует как «тихая деградация» (см. поведение ниже).

## Поведение (как используется блоком)

### SPA `karaoke-public`

1. `LatestNewsSection.vue` при `mounted()` вызывает `fetch('/api/public/news?page=0&size=5')`.
2. При HTTP 200:
   - Парсит JSON, извлекает `items`.
   - Применяет фронтовый фильтр (отбрасывает строки с пустым `link` или пустым `title`).
   - Если после фильтра осталось ≥1 строки — рендерит блок.
   - Если после фильтра 0 строк — блок не рендерится (тихая деградация).
3. При любом другом исходе (HTTP ≠ 200, сетевая ошибка, таймаут, невалидный JSON, исключение в JS) — блок не рендерится (FR-013 спеки — тихая деградация).
4. Состояние загрузки НЕ показывается (нет спиннера/«Загрузка новостей...») — посетитель либо видит 1-5 строк данных, либо не видит блок вовсе.

### Legacy Thymeleaf `karaoke-web`

1. `MainController.main()` (`karaoke-web/.../controllers/MainController.kt:50`) при рендеринге шаблона `main.html` вызывает `News.loadPublished(WORKING_DATABASE, limit = 5, offset = 0)` и кладёт результат в `model.addAttribute("latestNews", ...)`.
2. Шаблон `main.html` итерирует по `latestNews` (`th:each="n : ${latestNews}"`) и рендерит таблицу из 5 строк.
3. Строки с пустым `link` или пустым `title` отбрасываются через `th:if="${!#strings.isEmpty(n.link) and !#strings.isEmpty(n.title)}"`.
4. Если `latestNews` пуст или SQL бросил исключение — таблица рендерится без строк (или весь блок скрывается через `th:if="${!#lists.isEmpty(latestNews)}"`); HTTP-ответ — 200 OK.
5. Дата/время форматируется через `th:text="${#dates.format(n.publishAt, 'dd.MM.yyyy HH:mm')}"` или эквивалент (Spring Thymeleaf + стандартный форматтер).

## Идемпотентность / безопасность

- Эндпоинт идемпотентен (GET, без побочных эффектов).
- Доступен анонимным посетителям (без `SiteAuthInterceptor` — см. комментарий в `PublicNewsController.kt:11-17`).
- Никакой PII; никакой чувствительной информации; никаких rate-limits в спеке (эндпоинт уже существующий, его текущее поведение rate-limit'а не меняется).
- Никаких изменений в CORS — endpoint уже публичный.

---

## Что НЕ входит в контракт этой фичи

- Новый эндпоинт не создаётся.
- Сигнатура существующего эндпоинта не меняется.
- Формат `NewsDto` не меняется (см. `karaoke-app/.../model/NewsDto.kt`).
- Поведение существующих потребителей (`/news` лента с пагинацией, `/news/since` бейдж непрочитанных) не меняется.

## Версионирование

Не применимо — фича не меняет API. Контракт стабилен по построению (мы только переиспользуем).

Если в будущем потребуется расширить блок (например, добавить фильтр по категориям) — это будет отдельный контракт с новой версией или новым эндпоинтом; **не** поломка существующего.

# Контракт: `POST /api/getfreetimeslots`

Эндпоинт не переименовывается и не меняет HTTP-метод/путь/тип ответа — меняется
только содержательное наполнение результата (набор часов и корректность дат).
Используется исключительно admin-фронтендом (`webvue3`) для наполнения подсказок
поля «Дата публикации» в `SongEdit.vue` (см. `spec.md`, FR-005).

## Запрос

```http
POST /api/getfreetimeslots
```

Без параметров, без тела запроса (как и сейчас).

## Ответ

`200 OK`, `Content-Type: application/json`

```json
[
  "08.08.26 10:00",
  "08.08.26 11:00",
  "09.08.26 12:00",
  "08.08.26 13:00",
  "...",
  "08.08.26 22:00"
]
```

### До изменения (текущее поведение)

- Ровно **до 7** элементов (по одному на час 11:00–17:00), **меньше 7**, если для
  какого-то часа не было ни одной записи в `tbl_songs` — этот час просто
  отсутствует в ответе.
- Не гарантируется, что каждая дата в будущем: если последняя запись в этом
  часовом слоте была давно, дата вычисляется как «последняя дата + 1 день» и может
  оказаться в прошлом относительно текущего момента.

### После изменения (новый контракт)

- **Ровно 13** элементов, всегда — по одному на каждый час 10:00–22:00
  включительно, **независимо** от того, использовался ли этот час когда-либо
  раньше (FR-001, FR-003, SC-001).
- **Каждый** элемент — дата+время строго позже момента обработки запроса на
  сервере (FR-004, SC-002). Ни один элемент никогда не в прошлом и не равен
  текущему моменту.
- Формат строки не меняется: `dd.MM.yy HH:mm`.
- Порядок элементов — по возрастанию часа (10:00, 11:00, …, 22:00), как и раньше
  (по возрастанию часа в исходном списке подзапросов).

### Обратная совместимость с потребителем (`webvue3`)

`SongEdit.vue` использует ответ как есть, через `<option v-for>` в `<datalist>`
(`webvue3/src/components/Songs/edit/SongEdit.vue`, `list_free_time_slots`) — тип
элемента (`String`) и формат даты не меняются, поэтому фронтенд не требует правок.
Единственное наблюдаемое отличие для пользователя — больше вариантов в списке
подсказок и отсутствие вариантов, указывающих на прошедшую дату/время.

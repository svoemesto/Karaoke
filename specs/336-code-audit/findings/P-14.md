## Сверки

Спорное/недоказанное и подтверждения уже заведённых BR, без severity и без нового ID.

1. **BR-183 (P-15) подтверждается — новый BR не заводится.** В этой порции тот же механизм (`MltNode.toString()` без экранирования атрибутов/тела) достижим как минимум в: `MkoWatermark.kt:126` (`Karaoke.watermarkText` из настроек), `MkoSplashStart.kt:295, 316, 337` (`songVersionText`, `chordDescriptionText`, `commentText` — без обработки), `MkoSongText.kt:89` (ветка аккордов вставляет `mltText.text.split("|")[0]` без замены, тогда как `:94` для текста делает `&amp;amp;`), `MkoString.kt:166`, `MkoMelodyTabs.kt:230, 284` (ноты/лады). Отдельно: `MkoSplashStart.kt:260` делает только `replace("&", "&amp;")`, а `xmldata()` экранирует только `<` — при разборе атрибута `&amp;` станет `&`, то есть одиночное экранирование для вложенного XML недостаточно (в `MkoSongText`/`MkoScroller` по этой причине стоит двойное `&amp;amp;`). Это всё тот же корень BR-183; новые ID не нужны, но радиус/локации стоит добавить к BR-183 при его исправлении.
2. **`MkoScroller`, `MkoScrollerTrack`, `MkoScrollers` недостижимы — латентные дефекты не заведены.** Ни одна `SongVersion.producers` не содержит `SCROLLER`/`SCROLLERTRACK`/`SCROLLERS` (grep по `SongVersion.kt` пуст), а сеттеры `SCROLL_LINES`/`SCROLL_TRACK`/`TIME_TO_SCROLL_SCREEN_MS`/`HEIGHT_SCROLLER_PX` закомментированы (`MltProp.kt:104, 115, 123, 147`), писателей этих ключей в `props` нет. Поэтому `getCountChilds(...) = 0`, циклы `Mlt.kt:186–215` не создают ни одного узла, и код `MkoScroller*` не исполняется. Внутри него есть потенциальные падения (`subtitles.first()` на пустом списке — `MkoScroller.kt:90`, отрицательный `blank` при `scrollLineStartMs < scrollLineEndMsPrev` — `MkoScrollerTrack.kt:47–50`, неограниченный `while` по размеру шрифта — `MkoScroller.kt:82–85`), но по `rubric.md` §1 достижимости нет. Если фичу прокрутки вернут — это отдельный аудит, а не находка P-14.
3. **`Album.toDTO()` (N+1: автор + 2 картинки на альбом, `Album.kt:106–143`) не заведён.** Прямых вызывающих в `karaoke-app`/`karaoke-web` нет (grep), дайджест-эндпоинты используют пакетный `toDigestDTOs` (`Album.kt:178–217`, `ApiController.kt:6350–6354`), lite-эндпоинт — `toLiteDTOs`.

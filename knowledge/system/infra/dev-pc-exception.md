# dev-pc agent exception (Pass 282)

> **Домен**: system (infrastructure)
> **Компонента**: спецификация `021-dev-pc-agent-permissions` —
> исключения для агента на dev-машине.

## Назначение

Стандартное правило `AGENTS.md` раздела «Ограничения агента»:

> Пересобирать/перезапускать контейнер `karaoke-app` локально может
> **ТОЛЬКО пользователь** (не агент).

**Спецификация 021-dev-pc-agent-permissions** снимает это
ограничение **только** на машине `dev-pc` под пользователем `dev`.

## Когда применяется

- **host == `dev-pc`**
- **OS user == `dev`**

Если оба условия выполнены, агент может:
- Rebuild/restart `karaoke-app` локально.
- Rebuild/restart `webvue3`, `karaoke-public`, `webvue` (это и
  раньше было разрешено).
- Запросы к локальной БД (SELECT, INSERT, UPDATE, миграции, ALTER).
- **НЕ** распространяется на прод-БД (это по-прежнему требует
  прямого согласия пользователя, см. AGENTS.md).

## Где определено

- `AGENTS.md` — секция «Машинно-специфичные исключения (Pass 282)».
- `specs/021-dev-pc-agent-permissions/spec.md` — полная спецификация.

## Наша машина

Согласно `AGENTS.md`:

> **nsa-i9** / **nsa** (текущая) — НЕ `dev-pc/dev`. Следовательно,
> исключения Pass 282 **НЕ применяются** на этой машине.

Это значит, что в нашей сессии:
- ❌ Нельзя пересобирать/перезапускать `karaoke-app` без явного
  согласия.
- ✅ Можно править код.
- ✅ Можно запускать `gradle clean bootJar`, `npm run dev/build`.
- ✅ Можно пересобирать `karaoke-web` / `webvue3` / `karaoke-public`.

# Contract: видимость по статусу в публичном API (`/api/public/*`)

Эта фича не добавляет новых эндпоинтов и не меняет форму запроса/ответа
(request/response DTO). Меняется только **набор данных**, отдаваемый тремя
уже существующими эндпоинтами, в зависимости от роли аутентифицированного
пользователя. Ниже — контракт этого условного поведения.

## Общее правило

Для всех трёх эндпоинтов ниже: если запрос несёт заголовок
`Authorization: Bearer <token>`, токен резолвится в валидного `SiteUser`, и
`SiteUser.isEditor == true` — фильтр `id_status >= 3` **не применяется**.
Во всех остальных случаях (заголовка нет, токен невалиден/просрочен,
`isEditor == false`) поведение — как до этой фичи (specs/013).

## `GET /api/public/authors-tiles`

- **Без изменений**: query-параметры (`scope`), форма ответа
  (`List<AuthorTilePublicDto>`).
- **Изменение поведения**: подсчёт `songCount` для каждой плашки и сам
  список авторов (какие авторы включены/исключены как «без готовых песен»)
  для редактора считается по всем песням автора, а не только по
  `id_status >= 3`.

## `GET /api/public/zakroma`

- **Без изменений**: query-параметры (`author`, `specialBucket`, `anonId`,
  `referrer`), форма ответа (`List<ZakromaPublicDto>`).
- **Изменение поведения**: для редактора список альбомов/песен внутри
  закромов автора (и внутри спецзаказной плашки при `specialBucket=true`)
  включает песни всех статусов, а не только `id_status >= 3`.

## `GET /api/public/songs`

- **Без изменений**: query-параметры (`songName`, `author`, `text`, `album`,
  `anonId`, `referrer`), форма ответа (`List<SongPublicDto>`).
- **Изменение поведения**: для редактора результаты поиска включают песни
  всех статусов, а не только `id_status >= 3`.

## Не входит в контракт этой фичи

- `GET /api/public/authors` — список имён авторов без счётчиков; фильтрация
  по `id_status` там сегодня не применяется (список формируется независимо
  от статуса песен), поведение не меняется.
- `GET /api/public/song/{id}` — единичная страница песни по прямой ссылке;
  вне рамок этой фичи (см. Assumptions в spec.md, так же как в specs/013).
- `GET /api/public/stats` — публичные агрегированные счётчики главной
  страницы; не входит в понятия «закрома»/«поиск» из этой фичи, поведение
  не меняется.

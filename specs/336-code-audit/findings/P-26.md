## Сверки

Без severity; часть требует вердикта лида/владельца или проверки в браузере.

1. **publications.html:727,731,841 — `publishColors${id}` в разметке отсутствует.** В `unpublications.html:131` такой `<td>` есть, в `publications.html` его нет: `document.getElementsByName(nameColors)[0]` → `undefined` → `elementColors.style` бросает `TypeError` в ветке `case 'color'`. Сейчас недостижимо, потому что STOMP мёртв (P-26-02); станет дефектом сразу после восстановления брокера. Автор: `nsa <svoemesto@gmail.com>`, 2023-11-27.
2. **unpublications.html:103–105 — невалидная вложенность `<tr><div><td>`.** `<div>` не может быть ребёнком `<tr>`; по правилам разбора HTML (`in row`/`in table`) он выносится перед таблицей (foster parenting), а `<td>` вне табличного контекста отбрасывается. Требует проверки в браузере: если ячейки действительно пропадают, страница «Un-Публикации» рендерится без таблицы и `publishColors` (см. п.1) не существует и здесь. Автор: `nsa <svoemesto@gmail.com>`, 2023-11-27.
3. **unpublications.html:330–352 — кнопки фильтров ведут на `/publications`.** «Всё / С сегодня / …» на странице Un-Публикаций уводят на другой экран, а не фильтруют текущий. Намеренно (общие фильтры публикаций) или копипаста — не решено; функционального дефекта без вердикта не фиксирую.
4. **processes.html:251,257,263 против `AGENTS.md` Pass 381.** Кнопки Start/Stop/DelDone дёргают относительные `GET /process/start|stop|deletedone`; по Pass 381 эти эндпоинты (`MainController.kt:259,266,273`, без префикса `/api`) не проксируются nginx на `:7906`, а доступны только напрямую на бэкенде. Если страницу `/processes` открывают через `:7906`, кнопки получают 404; если напрямую — работают. Нужна фиксация точки входа, иначе это дефект (S3).
5. **processes.html:308–324 — `updateProcess(id)` шлёт все поля строки, а не изменённое.** При двух открытых вкладках сохранение одного поля перезатирает `name/status/order/priority/description/type` значениями из устаревшего DOM (lost update). При одном пользователе не проявляется.

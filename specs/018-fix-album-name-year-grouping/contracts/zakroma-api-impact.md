# Contract Impact: эндпоинты закромов

Фикс не меняет форму (shape) существующих контрактов — только корректность
содержимого списка `albums` внутри уже существующей структуры ответа. Новых
эндпоинтов, полей или параметров не добавляется.

## Затронутые эндпоинты (без изменений сигнатуры)

| Эндпоинт | Модуль | Потребитель | Изменение поведения |
|---|---|---|---|
| `GET /zakroma?author=...` | `karaoke-app` (`MainController.zakroma`) | Admin Thymeleaf-страница | `zakroma.albums` теперь содержит отдельный элемент на каждую (год, название)-пару вместо схлопывания одноимённых |
| `GET /zakroma?author=...` | `karaoke-web` (`MainController.zakroma`) | Legacy прод-страница | То же |
| `GET /api/public/zakroma?author=...&specialBucket=...` | `karaoke-web` (`PublicApiController.zakroma`) | `karaoke-public` (публичный SPA) | То же; включая ветку `specialBucket=true` (спецзаказная плашка), т.к. она тоже идёт через `buildFromSettings()` |

## Форма ответа (без изменений)

`List<Zakroma>` / `List<ZakromaPublicDto>`, где каждый `Zakroma` содержит
`albums: List<ZakromaAlbum>`. Состав полей `ZakromaAlbum`/`ZakromaAlbumSettings`
и их типы — без изменений (см. `data-model.md`).

## Наблюдаемая разница «до / после» (пример)

**До фикса** — автор с альбомами «Избранное» (2005, 8 песен) и «Избранное»
(2015, 6 песен):

```json
{
  "author": "Автор",
  "albums": [
    { "albumName": "Избранное", "year": 2005, "albumSettings": [ /* 14 песен, смешаны 2005+2015 */ ] }
  ]
}
```

**После фикса**:

```json
{
  "author": "Автор",
  "albums": [
    { "albumName": "Избранное", "year": 2005, "albumSettings": [ /* 8 песен */ ] },
    { "albumName": "Избранное", "year": 2015, "albumSettings": [ /* 6 песен */ ] }
  ]
}
```

## Обратная совместимость

- Клиенты (`webvue3`, `karaoke-public`), уже умеющие рендерить несколько
  альбомов одного автора (типичный случай — разные названия), не требуют
  изменений: просто получат больше корректных элементов массива `albums` для
  затронутых авторов.
- Для авторов без коллизий имён альбомов ответ побайтово идентичен
  (FR-005 spec.md, SC-003).

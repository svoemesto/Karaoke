## Что проверял

Утверждения находки P-69-09 (для обоих скриптов — `start_trainig.sh` и `resume_trainig.sh`):

1. Скрипт начинается с `cd ~/Karaoke/alignment-ml` — жёстко зашитый домашний путь.
2. Результат `cd` не проверяется — при неудаче скрипт продолжает работу в каталоге вызывающего.
3. Нет `set -e` / `set -u`.
4. Не проверяется наличие `.venv/bin/activate` ⇒ может активироваться чужой (или никакой) venv,
   а `python train.py` запускается системным интерпретатором без `torch`/`transformers`.
5. Код возврата скрипта — код последней команды, поэтому «упало на первом шаге и пошло не туда»
   маскируется.

## Вывод

**Не воспроизводится.** Оба скрипта переписаны: жёсткий путь убран, добавлены строгий режим,
проверки окружения и явный запуск интерпретатора venv по пути.

`alignment-ml/start_trainig.sh` (тело скрипта целиком):

```bash
set -euo pipefail

cd "$(dirname "${BASH_SOURCE[0]}")"

if [ ! -x .venv/bin/python ]; then
    echo "нет виртуального окружения: $(pwd)/.venv/bin/python" >&2
    echo "создайте его: python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt" >&2
    exit 1
fi

MANIFEST="${ALIGN_MANIFEST:-/sm-karaoke/system/alignment-dataset/manifest.jsonl}"
if [ ! -f "$MANIFEST" ]; then
    echo "нет файла манифеста: $MANIFEST" >&2
    echo "экспортируйте датасет в админке либо задайте ALIGN_MANIFEST" >&2
    exit 1
fi

exec ./.venv/bin/python train.py --manifest "$MANIFEST" "$@"
```

| Пункт находки | Текущее состояние |

| 1. жёсткий `cd ~/Karaoke/alignment-ml` | убран: `cd "$(dirname "${BASH_SOURCE[0]}")"` — каталог берётся из расположения самого скрипта |
| 2. результат `cd` не проверяется | устранено: `set -e` прерывает скрипт при неудаче `cd` |
| 3. нет `set -e` / `set -u` | добавлен `set -euo pipefail` |
| 4. venv не проверяется | явная проверка `[ ! -x .venv/bin/python ]` с понятным сообщением и `exit 1`; запуск — `exec ./.venv/bin/python train.py`, то есть интерпретатор venv по пути, а не системный `python` |
| 5. код возврата маскирует падение | `exit 1` при отсутствии venv/манифеста; `exec` — код возврата обучающего скрипта передаётся вызывающему без потери |

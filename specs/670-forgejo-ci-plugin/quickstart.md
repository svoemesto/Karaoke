# Quickstart: как проверить плагин «Forgejo CI»

Проверка идёт тремя слоями: юнит-тесты (быстро, без DSH и сети), маршрут
состояния (host работает), живой GUI (то, что видит человек). Успех установки
сам по себе **не** доказательство: регистрация слота не означает, что панель
видна.

## 0. Предпосылки

- репозиторий плагина склонирован в
  `/home/nsa/Karaoke/.scratch/karaoke/forgejo-ci-plugin/repo/` (ветка `main`);
- `FORGEJO_CI_TOKEN` резолвится из `~/.dsh/.credentials.yaml` (проверка — ниже,
  значение не печатать);
- DSH Web GUI открыт на `http://127.0.0.1:3080`;
- `plugin_manager` доступен **только** в сессии с approval (установку делает
  лид/владелец, не субагент).

## 1. Юнит-тесты (репозиторий плагина)

```bash
cd /home/nsa/Karaoke/.scratch/karaoke/forgejo-ci-plugin/repo
node --test            # ожидается: все тесты pass, 0 fail
```

Что обязано быть покрыто (тикет 10, критерий 7):

| Тест | Проверяет |
|---|---|
| `test/runs.test.mjs` | `duration` 331000000000 → `331` с; у ждущих `durationSec: null`; ссылка из `index_in_repo` (398 → `/runs/32`); нулевая метка `1970-01-01` → «нет значения» |
| `test/buffer.test.mjs` | пурж: буфер отдаёт последние 5 даже когда API вернул 1; обновление существующего `id` не дублирует; вытеснение по `id` |
| `test/snapshot.test.mjs` | `stale` после 45 с без успеха; `queue-stuck` после 10 мин без активности; `jobs: null` при завершённом последнем прогоне и заполнен при `running`; `lastOkAt` не теряется при ошибке |
| `test/secret.test.mjs` | `JSON.stringify(snapshot)` не содержит значения тестового токена ни в одном поле |
| `test/config.test.mjs` | дефолты при пустом конфиге; отказ на мусорный `tokenRef`, `pollMs < 5000`, `runsLimit` вне 1..20, относительный `routePath` |
| `test/tools.test.mjs` | выбор самого нового прогона; уже терминальный → `waitedSec: 0`; таймаут → `timedOut: true`; неизвестный `runId` → ошибка со списком id; `timeoutSec > 600` → `timeout-too-long` |
| `test/schema.test.mjs` | `buildSnapshot()` содержит все `required`-поля схемы; `enum` поля `error` совпадает со словарём `lib/forgejo.js`; `schemaVersion` — целое ≥ 1; копия схемы совпадает с оригиналом по `required` и `enum` |

## 2. Маршрут состояния (host живёт)

```bash
curl -s http://127.0.0.1:3080/forgejo-ci/state | python3 -m json.tool | head -40
```

Ожидается: `stale: false`, непустой `runs`, `runner.name == "nsa-i9"`,
`lastOkAt` свежий (< 20 с), ответ < 100 мс (`-w '%{time_total}'`).

Проверка отсутствия утечки (значение токена не печатать, только факт):

```bash
curl -s http://127.0.0.1:3080/forgejo-ci/state > /tmp/state.json
grep -c "$(python3 - <<'PY'
import re
print(re.search(r'^\s{2}FORGEJO_CI_TOKEN:\s*(\S+)', open('/home/nsa/.dsh/.credentials.yaml').read(), re.M).group(1))
PY
)" /tmp/state.json    # ожидается 0
```

## 3. Tool'ы (агент)

В живой сессии:

1. `forgejo_ci_status` — ответ < 2 с, в ответе те же прогоны, что в маршруте;
   поля `stale`, `lastOkAt`, `error` на месте.
2. `forgejo_ci_status` с `{"runs": 1}` — ровно один прогон.
3. `forgejo_ci_wait` с `{"runId": <id завершённого>}` — ответ сразу,
   `waitedSec: 0`, `timedOut: false`.
4. `forgejo_ci_wait` с `{"timeoutSec": 10}` во время активного прогона — через
   ~10 с `timedOut: true` и текущий статус.
5. `forgejo_ci_wait` с `{"runId": 1}` — ошибка `unknown-run` со списком
   известных id.
6. В обоих ответах есть `stale` и `lastOkAt` (FR-008), значение токена — нет.

## 4. Живой GUI (человек)

1. Перезагрузить страницу `http://127.0.0.1:3080`.
2. Сайдбар: иконка CI; при упавшем последнем прогоне — красная точка, при
   идущем — пульс.
3. Клик по иконке → панель: строки прогонов (номер, ref, событие, статус,
   длительность), строка раннера, строка «сейчас бегут …» (только при активном
   прогоне), полоса `stale` при недоступном Forgejo.
4. Клик по строке прогона → страница Forgejo в новой вкладке.
5. Во время прогона дождаться завершения: toast ≤ 15 с; падение — заметный,
   успех — тихий; повторной перерисовки нет; клик открывает прогон.
6. DevTools: в DOM, `localStorage` и сетевых ответах нет значения токена.

## 5. Деградация

```bash
# временно увести адрес в никуда (правка config в cordis.patch.yml профиля или
# подмена baseUrl на несуществующий хост) → перезагрузить страницу
```

Ожидается: панель показывает прошлые данные + полосу «данные устарели:
последний успех HH:MM:SS»; toast'ов нет; процесс DSH жив; после возврата адреса
пометка исчезает сама без перезапуска.

Второй сценарий: `tokenRef` указывает на несуществующую ссылку → панель
показывает «токен не настроен» (не пустой экран, не 500), tool отвечает
`error: "token-missing"`.

## 6. Снятие плагина (FR-018)

```bash
# plugin_manager set_plugin/remove_bundle (сессия с approval)
```

Ожидается: иконка, панель и toast'ы исчезают без перезапуска процесса;
`cordis_inspect_query` `Slots.listSubTree(root: sidebar.panellist)` больше не
содержит occupant `forgejo-ci`; маршрут `/forgejo-ci/state` отвечает 404.

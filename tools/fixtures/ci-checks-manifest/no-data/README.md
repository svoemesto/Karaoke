# Фикстура «нет данных» (tools/check-ci-checks-manifest.sh)

Здесь намеренно НЕТ файлов `.forgejo/workflows/lint.yml` и `.github/workflows/lint.yml`:
гейт должен вернуть код **2** («проверка не выполнена»), а не 0 и не 1.

Каталог не пуст (в git не отслеживаются пустые каталоги) — этот README существует
только для того, чтобы фикстура попала в репозиторий.

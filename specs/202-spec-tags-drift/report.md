# Отчёт: #202 — расхождение syncMarkersFromSpecTags

**PR:** #611, ветка `519-fix-spec-tags-dedup`. **Severity: S1.**

## Причина

Дрейф с 2026-08-10: спека 163 сознательно не распространила фикс на публичную
копию. Нарушен контракт `contracts/tag-registry.md:17`.

Публичный редактор зовёт функцию на каждое нажатие клавиши (debounce 3000 мс →
saveNow), поэтому раздувание массива маркеров уезжало в черновик без участия
пользователя.

## Два расхождения

1. Дедупликация по индексному окну вместо временного диапазона — не идемпотентна
   (sortMarkers вытесняет маркер за пределы окна).
2. Отсутствовал FIX #018 (защита `time < 0.5`).

## Сделано

- karaoke-public: дедуп → временной диапазон; добавлена защита FIX #018.
- webvue3: временная дедупликация уже была, добавлена только защита FIX #018.

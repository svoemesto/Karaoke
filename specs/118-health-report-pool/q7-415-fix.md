## Состояние дебага 415

**Бэкенд**: работает. `POST /api/health/cache/active-song-ids` через nginx возвращает **200**.

**Код в bundle `index-D-YFYPno.js`**: правильный — `body: {activeSongIds: t}, headers: {"Content-Type": "application/json"}`.

**Возможные причины**:
1. Кеш браузера — нужно **hard refresh** (`Ctrl+Shift+R`).
2. Service Worker — нужно unregister.
3. Если 415 сохраняется после hard refresh, нужно проверить в DevTools:
 - Network → Headers → Request Headers → Content-Type
 - Network → Payload → `{"activeSongIds":[...]}`

Дополнительный фикс в коде:
- Явно указываю `headers: { 'Content-Type': 'application/json' }` в sendActiveSongIds (раньше
  полагался на автоопределение promisedXMLHttpRequest).

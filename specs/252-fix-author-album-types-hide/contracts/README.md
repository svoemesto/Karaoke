## Резюме

Изменение не вводит и не модифицирует **никаких внешних контрактов**:

- Не добавляет REST-endpoint (нет нового API).
- Не меняет формат стрима `meta`/`song`/`done` для `/api/public/zakroma`
  (спек 181 + 239).
- Не меняет DTO `ZakromaPublicDto` (спек 012 + 030 + 031) и
  `AlbumTypeSummaryDto`.
- Не меняет схему БД (PostgreSQL), sync-флаги, миграции.
- Не меняет Vuex-стейт модуля `zakroma`, `auth`, `cart`,
  `playlists`, `subscriptions`.
- Не публикует и не потребляет JSON-схемы, CLI-аргументы,
  публичные API библиотек.

## Что формально контрактом НЕ является

- **CSS-маркеры** (`.km-filter-bar`, `.km-album-controls-bar`,
  `.km-author-header-sticky`, `.km-header`) — это **scoped-CSS** внутри
  Vue SFC `ZakromaView.vue` (и попутно `.km-header-sticky` в `AppHeader.vue`).
  На публичный API не выносятся и другими страницами/приложениями
  не используются (scoped-классы Vue). Поэтому отдельный
  «CSS-контракт» оформлять не нужно.

- **DOM-структура** `<div class="km-filter-bar">` и
  `<div class="km-album-controls-bar">` — это приватная разметка Vue view,
  внешними селекторами не используется (не тестируется снаружи, не
  парсится тестами).

## Назначение

Сценарии ручной проверки фичи на dev-pc (или в production-like окружении). Существующие юнит-тесты в `karaoke-app/src/test` — `@Disabled` (Constitution § «Тесты»), проверка делается пользователем. Шаблон заимствован из `specs/082-fix-import-folder-oom/quickstart.md`.

## Предусловия

- `karaoke-app` собран и работает: `cd /sm-karaoke/system/deploy && bash do.sh build_app && bash do.sh start_app` (или `build_start_app` — одной командой).
- Папка для тестов: `/sm-karaoke/work/_test_238/` (или любая другая временная папка, доступная контейнеру).
- Доступ к admin-интерфейсу `webvue3` (главная страница → кнопка «Добавить файлы из папки»).
- Логи `karaoke-app` доступны (`docker logs -f karaoke-app` или `do.sh logs_app`).

## Сценарий 1 — Поиск «родителя» НЕ выходит за пределы того же автора (FR-001, FR-002, SC-001)

**Цель**: убедиться, что новая песня автора B не получает текст/маркеры от одноимённой песни автора A.

**Шаги**:
1. Создать папку `/sm-karaoke/work/_test_238/cross_author/`.
2. Подготовить в ней файл `2024 (01) [Автор A] - Звезда.flac` (любой flac-файл, валидный для импорта).
3. Запустить «Добавить файлы из папки» → путь `/sm-karaoke/work/_test_238/cross_author/`.
4. После завершения — в БД или в UI найти созданную песню «Звезда» у автора A. Через редактор (или прямой SQL `SELECT * FROM tbl_songs WHERE song_name='Звезда'`) убедиться, что у неё есть `source_text`, `result_text`, `source_markers` (любой непустой набор — для имитации «готового оригинала»).
5. Создать **новую** папку `/sm-karaoke/work/_test_238/cross_author_2/` с файлом `2024 (02) [Автор B] - Звезда.flac` (другой автор, тот же трек).
6. Запустить «Добавить файлы из папки» → путь `/sm-karaoke/work/_test_238/cross_author_2/`.
7. После завершения — найти созданную песню «Звезда» у автора B.

**Ожидаемый результат**:
- У песни автора B `source_text` = пусто (или равен только её собственной «обложке», но не от автора A).
- `root_id` у песни автора B = 0 или = её собственный `id` (не id песни автора A).
- В логах `karaoke-app` НЕТ записей вида «найден оригинал id=... другой автор» или `applyDuplicateOriginal` с cross-author привязкой.

**Если наблюдается иначе** — фича не работает, см. `contracts/find-parent-same-author.md` и `Utils.kt:4296`.

## Сценарий 2 — Поиск «родителя» у того же автора работает как раньше (FR-003, SC-002)

**Цель**: убедиться, что для случая «того же автора» поведение не regression'нулось.

**Шаги**:
1. Использовать песню «Звезда» у автора A из сценария 1 (с непустым `source_text`).
2. Создать папку `/sm-karaoke/work/_test_238/same_author/` с файлом `2024 (03) [Автор A] - Звезда.flac` (тот же автор, тот же трек).
3. Запустить «Добавить файлы из папки».

**Ожидаемый результат**:
- Новая песня получает `source_text`/`result_text`/`source_markers` от первой песни (то же, что было).
- `root_id` указывает на id первой песни.
- В логах — запись «найден оригинал» (или эквивалент), в поле `sameAuthorOnly = true`.

## Сценарий 3 — Автообложка создаётся для нового альбома с одним графическим файлом (FR-005, FR-006, FR-007, SC-003)

**Цель**: убедиться, что автообложка создаётся для **нового** альбома при ровно одном графическом файле в `rootFolder`.

**Шаги**:
1. Создать папку `/sm-karaoke/work/_test_238/2024 - Тестовый альбом/` (соглашение об именовании папок альбома).
2. Положить в неё 2-3 файла: `2024 (01) [Какой-то автор] - Песня 1.flac`, `2024 (02) [Какой-то автор] - Песня 2.flac`, `2024 (03) [Какой-то автор] - Песня 3.flac`.
3. Положить в неё **ровно один** графический файл, например, `cover.jpg` (любого размера и соотношения сторон).
4. Запустить «Добавить файлы из папки» → путь `/sm-karaoke/work/_test_238/`.

**Ожидаемый результат**:
- В БД появилось 3 новые песни + 1 новый альбом «Тестовый альбом».
- В папке `/sm-karaoke/work/_test_238/2024 - Тестовый альбом/` появился файл `LogoAlbum.png` — открыть его (например, `file LogoAlbum.png` → должен показать «PNG image data, 400 x 400»).
- В той же папке появился файл `LogoAlbum.preview.png` (превью).
- В таблице `tbl_pictures` появилась запись с `name = "Какой-то автор - 2024 - Тестовый альбом"` и `full` (base64) — содержимое совпадает с `LogoAlbum.png`.
- В UI (страница «Альбомы» или «Закрома автора») у альбома отображается обложка (не плейсхолдер «Нет изображения»).
- В MinIO (если настроен — см. `Pictures.storageFileName` логику) обложка доступна по тому же URL, что и ручные обложки (`/api/picture/file?file=...`).

## Сценарий 6 — Альбом уже существует → автообложка НЕ перезатирает (FR-009, SC-005)

**Цель**: убедиться, что для существующего альбома лежащий рядом графический файл не приводит к пересозданию обложки.

**Шаги**:
1. Использовать альбом из сценария 3 (с уже созданной автообложкой).
2. Положить в ту же папку ещё один файл песни: `2024 (04) [Какой-то автор] - Песня 4.flac` (новый, не импортированный).
3. Запустить «Добавить файлы из папки».

**Ожидаемый результат**:
- Новая песня добавлена, привязана к существующему альбому.
- `LogoAlbum.png` остался **прежним** (тот же `md5`, тот же размер, та же картинка) — никакой перезаписи.
- В `tbl_pictures` запись с тем же `id`, `full` не изменилось.
- В логах — НЕТ записей об обновлении `Pictures`/`LogoAlbum.png` для этого альбома.

## Сценарий 7 — Много-дисковый альбом → обложка в каждой `rootFolder` (Q1)

**Цель**: убедиться, что для много-дискового альбома обложка ищется и сохраняется в каждом диске отдельно.

**Шаги**:
1. Создать папку `/sm-karaoke/work/_test_238/2024 - Двухдисковый/CD1/` с файлом `2024 (01) [Автор] - Песня.flac` + графический файл `cover1.jpg`.
2. Создать папку `/sm-karaoke/work/_test_238/2024 - Двухдисковый/CD2/` с файлом `2024 (02) [Автор] - Песня.flac` + графический файл `cover2.jpg`.
3. Запустить «Добавить файлы из папки» → путь `/sm-karaoke/work/_test_238/`.

**Ожидаемый результат**:
- В обеих подпапках `CD1/` и `CD2/` появились `LogoAlbum.png` и `LogoAlbum.preview.png` (содержащие разные картинки — `cover1.jpg` и `cover2.jpg` соответственно).
- Альбом один (один `tbl_albums` row), привязан к обеим песням.
- `tbl_pictures` — запись одна (по `pictureNameAlbum`); какой `LogoAlbum.png` будет в `full` — зависит от того, какой диск обработался первым; это known limitation (см. `research.md` R5).

## Сценарий 8 — `LogoAlbum.png` + `cover.jpg` в папке → автообложка не создаётся (Q3, FR-008)

**Цель**: убедиться, что уже существующий `LogoAlbum.png` (или `LogoAlbum.preview.png`) считается обычным графическим файлом и при наличии ещё одного «настоящего» автообложка не создаётся.

**Шаги**:
1. Создать папку `/sm-karaoke/work/_test_238/2024 - Альбом с двумя файлами/` с 2 файлами песен + двумя графическими файлами: `LogoAlbum.png` (любой существующий PNG, например пустой 1×1) + `cover.jpg`.

**Ожидаемый результат**:
- Автообложка НЕ создаётся (два кандидата — `LogoAlbum.png` и `cover.jpg`).
- Существующий `LogoAlbum.png` остаётся как есть.
- Импорт песен прошёл успешно.

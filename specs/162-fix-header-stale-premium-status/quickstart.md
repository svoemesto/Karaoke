# Quickstart: проверка фикса «устаревший премиум-статус в шапке»

Ручная проверка — в проекте нет CI-тестов для `karaoke-public`
(см. `plan.md` → Technical Context → Testing). Все сценарии ниже — из
`spec.md` (Acceptance Scenarios, User Story 1).

## Предпосылки

- Локальный стек поднят (`karaoke-public`, `karaoke-web`, БД) —
  см. `DEVELOPMENT.md` / `deploy/do.sh`.
- Тестовый аккаунт `SiteUser` с возможностью вручную переключать
  премиум-статус (через админку `webvue3` — карточка пользователя, поля
  `isPremium`/`sponsrPremiumUntil`/`sitePremiumUntil`, либо напрямую в
  локальной БД согласно правам агента на машине `dev-pc`).
- Открыт `karaoke-public` в браузере, залогинен под тестовым аккаунтом.

## Сценарий 1 — снятие премиума без перезагрузки (US1, AS1)

1. Залогиниться под аккаунтом с активным премиумом. Убедиться, что в шапке
   виден значок 🪙 рядом с именем.
2. Не перезагружая страницу и не переходя на `/account`,
   `/account/editor/tasks` или `/account/editor/work` — снять премиум у
   этого аккаунта на сервере (через админку/БД).
3. Дождаться следующего фонового тика обновления (Decision 2, research.md:
   ≤5 минут).
4. **Ожидается**: значок 🪙 исчезает из шапки сам, без действий пользователя.

## Сценарий 2 — обновление страницы отражает актуальный статус (US1, AS2)

1. Повторить шаги 1-2 из сценария 1.
2. Сразу перезагрузить страницу (F5), не дожидаясь фонового тика.
3. **Ожидается**: шапка сразу показывает статус без премиума.

## Сценарий 3 — logout/login отражает актуальный статус (US1, AS3)

1. Повторить шаги 1-2 из сценария 1.
2. Выйти из аккаунта и зайти заново.
3. **Ожидается**: шапка сразу показывает статус без премиума.

## Сценарий 4 — регрессия: активный премиум не мигает (US1, AS4)

1. Залогиниться под аккаунтом со стабильно активным премиумом (подписка не
   меняется).
2. Пользоваться сайтом (переходы между страницами, ожидание) в течение
   нескольких фоновых тиков (10+ минут).
3. **Ожидается**: значок 🪙 в шапке ни разу не пропадает и не мигает.

## Сценарий 5 — симметричный случай: оформление премиума (US1, AS5)

1. Залогиниться под аккаунтом без премиума. Убедиться, что значка 🪙 в
   шапке нет.
2. Не перезагружая страницу, оформить/выдать премиум этому аккаунту на
   сервере.
3. Дождаться следующего фонового тика (≤5 минут).
4. **Ожидается**: значок 🪙 появляется в шапке сам.

## Дополнительно — edge case «сетевой сбой не показывает ложный премиум» (FR-005)

1. Залогиниться под аккаунтом без премиума.
2. Временно заблокировать сетевые запросы к `/api/public/auth/me` (например
   через DevTools → Network → block request URL) на время одного-двух
   фоновых тиков.
3. **Ожидается**: премиум-значок не появляется (никакого «оптимистичного»
   включения из-за ошибки); после снятия блокировки следующий успешный тик
   отражает реальный статус.

## Где смотреть при провале сценария

- `karaoke-public/src/composables/useAuth.js` — `fetchMe()` и таймер
  фонового обновления.
- `karaoke-public/src/components/AuthStatusWidget.vue` — читает
  `user.effectivePremium`.
- Вкладка Network в DevTools — убедиться, что `GET /api/public/auth/me`
  реально уходит на сервер каждые ~5 минут, пока пользователь залогинен.

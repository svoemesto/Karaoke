# 163 — Регрессии редакторов после внедрения спецтегов (LiveDoc)

> Drill-down — [specs/163-fix-song-editor-regressions/spec.md](../../specs/163-fix-song-editor-regressions/spec.md).

## Что делает

После внедрения «спецтегов» (`~Куплет~`, `~Припев~`, `~comment:...~`) в lyrics
в админке появились две регрессии в редакторах:

1. **Полноценный SubsEdit** (с вейвформой) начал тормозить при загрузке —
   на вейвформе на мгновение видны «дубли» всех маркеров в нулевой позиции
   (визуальный артефакт, в массиве не дубли — рендер buggy).
2. **Облегчённый редактор** (модальный) перестал сохранять изменения.

**Фикс 1 (perf)**: SubsEdit:
- Ленивая отрисовка маркеров (первые N + rest по требованию).
- Отключить двойной проход рендера при mount (race condition).
- Виртуализация маркеров на вейвформе (не рисовать тысячи одновременно).

**Фикс 2 (data)**: облегчённый редактор:
- Проверить, что `setContent` (pass 019 из `specs/019-fix-setcontent-resets-position`)
  не сбрасывает позицию при спецтегах.
- При ошибке сохранения — **явный** индикатор «Ошибка сохранения», НЕ тишина.
- При попытке закрыть редактор после **неудачного** сохранения — **блокирующее
  предупреждение** («Вы уверены, что хотите закрыть без сохранения?»).

## User Stories (краткий список)

- **US1** (P1): Изменения в облегчённом редакторе снова сохраняются на сервер.
- **US2** (P2): Полноценный SubsEdit не тормозит и не показывает «дублей» маркеров.

## Functional Requirements (указатель)

- **FR-001**: Автосохранение облегчённого редактора реально доезжает до БД (через `/api/songeditor/light`).
- **FR-002**: При ошибке сохранения — красный индикатор «Ошибка сохранения», НЕ «Сохранено ✓».
- **FR-003**: Блокирующее предупреждение при попытке закрыть редактор после ошибки.
- **FR-004**: SubsEdit рендерит маркеры постепенно (≤ 10% сверх времени загрузки без спецтегов).
- **FR-005**: Виртуализация маркеров на вейвформе.

## Acceptance Criteria

- [ ] **AC1**: Облегчённый редактор → правка → автосохранение → F5 → правки на месте.
- [ ] **AC2**: Со спецтегами — то же (правки сохраняются, спецтеги не ломаются).
- [ ] **AC3**: При сетевой ошибке — красный индикатор, не «Сохранено».
- [ ] **AC4**: Закрытие после ошибки → блокирующее предупреждение с явным подтверждением.
- [ ] **AC5**: SubsEdit ≤ 10% сверх времени загрузки без спецтегов.
- [ ] **AC6**: На вейвформе нет «дублей» маркеров в нулевой позиции.

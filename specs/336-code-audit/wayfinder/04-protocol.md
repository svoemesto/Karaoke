## Question

Написать протокол одной порции аудита и ревью лида — так, чтобы 3 субагента работали одинаково и результат склеивался без расхождений.

В протоколе:

- размер порции и правило нарезки (из inventory);
- промпт субагента: read-only, запрет правок кода/БД/перезапусков, обязательные доказательства, формат записи, что делать со спорным;
- шаблон записи BR-NN (все поля, включая автора git blame и SHA);
- реестр находок и дедупликация («одна причина — одна запись», зеркала);
- чек-лист проверки лида по диску (цитата существует, строки совпадают, severity по рубрике, класс по рубрике, автор подтверждён git blame);
- проверка покрытия: каждая порция сверяется с ведомостью, неотчитавшиеся файлы возвращаются в работу;
- границы эмпирики на nsa-i9 (что можно без согласия, как помечать «требует согласия»);
- сборка `bug-report.md`, разделы, вложение в #336 через API, git-поток (docs-only PR).

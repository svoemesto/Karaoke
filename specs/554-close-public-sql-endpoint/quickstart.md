# Quickstart: проверка 554 — закрытие публичного доступа к `POST /changerecords`

Документ — руководство по проверке, а не инструкция реализации. Код живёт в `tasks.md`.

## Предпосылки

- Репозиторий: `/home/nsa/Karaoke`, ветка `554-close-public-sql-endpoint`.
- Gradle с `GRADLE_USER_HOME=/home/nsa/Karaoke/.gradle` (Hard Gate R-372).
- Локальный стенд не требует БД: проверка идёт через unit-тесты.
- Для проверки nginx-конфига — контейнер с nginx (локальный, без согласия на прод-деплой).

## Проверка 1. Правка сервира (должна отменять запрос без секрета)

```bash
cd /home/nsa/Karaoke
GRADLE_USER_HOME=/home/nsa/Karaoke/.gradle ./gradlew :karaoke-web:test --tests '*ChangeRecords*'
```

Ожидаемо:

- тест «без заголовка → 403, SQL не выполняется» — **зелёный**;
- тест «с корректным заголовком → действия применяются» — **зелёный**;
- тест «секрет не настроен, заголовок пустой → 403» — **зелёный** (ловушка образца, см. research D2).

Обратная проверка: на коде **до** правки первый тест падает (запрос выполняется) — это и есть «до/после».

### P-78-03: .github/workflows/lint.yml:295–317 — BUILD (S2)
- Что не так: шаг «No direct commits to master (Pass 353, final safety net)» выполняется в job `knowledge-structure`, где checkout идёт **без `fetch-depth`**, то есть с глубиной 1 (`actions/checkout@v4` по умолчанию). - Доказательство:
  ```
          DIRECT_COMMITS=$(git log --first-parent origin/master --since=24.hours --no-merges --pretty=format:"%H %s" | wc -l | tr -d ' ')
  ```
  (`.github/workflows/lint.yml:304`, SHA 1977838a); checkout в этом job — `uses: actions/checkout@v4` (`:235`) без `with: fetch-depth`; при глубине 1 истории нет, и команда завершается пустым выводом.

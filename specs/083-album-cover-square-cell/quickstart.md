# Quickstart: Альбомы — квадратная ячейка обложки альбома

**Phase 1 output for**: `083-album-cover-square-cell`
**Date**: 2026-07-29
**Spec**: [spec.md](./spec.md)
**Research**: [research.md](./research.md)

## Что проверяем

После правки `webvue3/src/components/Albums/AlbumsTable.vue`:
- Колонка `(альбом)` в таблице альбомов — квадратная (54×54px).
- Картинки вписаны пропорционально, без обрезки.
- Плейсхолдер «Нет изображения» занимает весь квадрат.
- Клик по preview по-прежнему открывает `AlbumCoverModal` (нет
  регрессии).
- Колонка `(автор)` остаётся как была (прямоугольная).
- Пагинация, фильтр, сортировка работают как раньше.

## Предусловия

- Frontend-сборка проходит: `cd webvue3 && npm run build` — exit 0.
- ESLint проходит: `cd webvue3 && npm run lint:check` — exit 0.
- Контейнер `webvue3` поднят локально (на `dev-pc`/`dev` —
  `cd deploy && bash do.sh start` или эквивалент).
- В БД есть хотя бы один автор с ≥2 альбомами, у части альбомов
  обложка есть, у части — нет (для проверки плейсхолдера).
- В БД есть альбом с обложкой неквадратного соотношения сторон
  (например, 400×300) — для проверки `object-fit: contain`.

## Сценарии валидации

### S1. Базовая проверка: ячейка квадратная

1. Открыть `http://localhost:5173/Albums` (или порт, на котором поднят
   `webvue3` локально).
2. Нажать кнопку фильтра (правый нижний угол) → выбрать автора с
   альбомами → «Применить».
3. Дождаться загрузки таблицы.
4. **Ожидаемо**: каждая ячейка в колонке `(альбом)` визуально квадратная
   (ширина = высота, обе ≈ 54px). Колонка `(автор)` — прямоугольная
   (ширина > высоты), как была.
5. **Проверка**: в DevTools (F12) выделить ячейку `<td>` колонки
   `(альбом)` → `Computed` → `width` ≈ `54px`, `height` ≈ `54px`.
   Поле `offsetWidth === offsetHeight`.

### S2. Проверка с обложкой (пропорциональное вписывание)

1. В отфильтрованной таблице найти альбом с обложкой 1:1 (квадратной).
2. **Ожидаемо**: обложка отображается во весь квадрат 50×50px, без
   полей по бокам/сверху/снизу.
3. Найти альбом с обложкой 4:3 (горизонтальная).
4. **Ожидаемо**: обложка вписана в квадрат без обрезки; сверху/снизу —
   пустое пространство (чёрный фон ячейки, см.
   `AlbumsTable.vue:727` `background-color: black`).
5. Найти альбом с обложкой 3:4 (вертикальная).
6. **Ожидаемо**: обложка вписана в квадрат без обрезки; по бокам —
   пустое пространство.

### S3. Проверка плейсхолдера «Нет изображения»

1. В отфильтрованной таблице найти альбом без обложки (поле
   `albumPicturePreviewUrl` пустое).
2. **Ожидаемо**: ячейка содержит текст «Нет изображения» на чёрном
   фоне, текст центрирован, ячейка остаётся квадратной.
3. В DevTools: `<td>` ≈ 54×54px, дочерний `<div class="no-image-placeholder">`
   центрирован через `display: flex; align-items: center; justify-content: center`
   родителя.

### S4. Регрессия: клик по ячейке открывает `AlbumCoverModal`

1. Кликнуть по preview обложки в колонке `(альбом)` (для альбома с
   `songsCount > 0`).
2. **Ожидаемо**: открывается модалка `AlbumCoverModal` с теми же шагами
   `view` / `searching` / `results` / `cropping`, что и до правки.
3. Закрыть модалку без изменений.
4. **Ожидаемо**: таблица не сломана, текущая страница и фильтр сохранены.

### S5. Регрессия: высота остальных строк не изменилась

1. Пролистать таблицу вниз (изменить `currentPage`).
2. **Ожидаемо**: высота строк осталась прежней (≈ 54px), колонки
   `Название`, `Год`, `Тип`, `Песен`, `Порядок` не «поджались» и не
   «распёрлись» по высоте.
3. **Проверка**: в DevTools выделить `<tr>` → `offsetHeight` ≈ 54px
   (допуск ±2px на line-height).

### S6. Регрессия: пагинация и фильтр работают

1. Изменить `perPage` (если такая опция есть в пагинаторе) или
   перейти на следующую страницу.
2. **Ожидаемо**: таблица перестраивается, ячейки `(альбом)` остаются
   квадратными на всех страницах.
3. Сбросить фильтр и применить новый.
4. **Ожидаемо**: новый набор альбомов отображается с теми же
   квадратными ячейками.

### S7. Регрессия: колонка `(автор)` не изменилась

1. В той же таблице посмотреть на колонку `(автор)`.
2. **Ожидаемо**: ширина колонки `(автор)` ≈ 125px (как было),
   ячейка прямоугольная.
3. **Проверка**: `git diff AlbumsTable.vue` НЕ должен показывать
   правок поля `authorPicture` в `albumDigestFields` или класса
   `.preview-image`, относящихся к колонке автора.

### S8. Zoom/Resize: квадрат сохраняется

1. В браузере изменить масштаб (Ctrl+/Ctrl-) на 75%, 100%, 125%, 150%.
2. **Ожидаемо**: ячейка `(альбом)` остаётся квадратной (CSS-значения
   в пикселях, не в `em`/`%`, поэтому пропорции сохраняются).
3. Изменить ширину окна браузера (от 800px до 1920px).
4. **Ожидаемо**: ячейка остаётся квадратной; остальные колонки
   перераспределяются как обычно (через `minWidth`/`maxWidth` в полях).

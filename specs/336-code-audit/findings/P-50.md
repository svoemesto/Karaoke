### P-50-02: karaoke-public/e2e/public-editor.spec.js:44–58 — TEST (S3)
- Что не так: e2e-проверка «контракт развёртывания» опирается на **текст минифицированного бандля**: регулярки `/\.time>=\w+&&\w+\.time<=/` и `/<\s*\.5\s*&&/` предполагают конкретную форму минифицированного вывода. Любая смена версии минификатора/настроек сборки меняет текст и ломает тест, хотя поведение то же; наоборот, тест может «проходить» по случайно совпавшему фрагменту. Кроме того, бандл выбирается перебором всех `assets/*.js` с условием `body.includes('markertype')` — при нескольких подходящих бандлах берётся **последний**, что недетерминированно.
- Доказательство:
  ```
      expect(bundle, 'дедуп по времени (m.time >= …) должен быть в бандле').toMatch(
        /\.time>=\w+&&\w+\.time<=/,
      )
  ```
  (`karaoke-public/e2e/public-editor.spec.js:49–51`, SHA 1977838a); выбор бандла — `if (body.includes('markertype')) bundle = body` (`:44`).
- Путь: обновление Vite/terser или рефакторинг → тест падает без дефекта (ложная тревога) либо, наоборот, не замечает реальное исчезновение логики, если фрагмент остался в другом бандле.
- Поправка: проверять поведение, а не текст бандла (например, прогонять публичный редактор в браузере и проверять DOM), либо пометить проверку как «дымовая» и не считать её блокирующей.
- Найдено в: порция P-50, аудит лида.
- Автор (git blame): Ilya (boss) (2026-09-30, `public-editor.spec.js:50–51` — `ccda17e66`).

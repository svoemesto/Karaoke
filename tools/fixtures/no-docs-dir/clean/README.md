# ФИКСТУРА (tools/fixtures/no-docs-dir/) — замороженный снимок

Снимок состояния, которое guard `tools/check-no-docs-dir.sh` обязан пропустить:
каталога `docs/` нет — ни на диске, ни среди отслеживаемых файлов.

Каталог намеренно содержит только этот README: он нужен, чтобы пустая
фикстура существовала в git (пустые каталоги git не хранит).

Ожидаемый результат прогона:

```bash
bash tools/check-no-docs-dir.sh --root tools/fixtures/no-docs-dir/clean
# код возврата: 0 (нарушений нет)
```

Контекст: FR-012, FR-001, SC-005, ADR-0011.

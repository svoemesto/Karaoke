## Сверки (спорное, без severity)

1. **`addEndMarker()` и `duration = 0` — уже описано в P-46-02, новой записи нет.** «`      const duration = this.ws.getDuration()`» (`SubsEdit.vue:3234`) не проверяет готовность аудио: до `decode` (и навсегда, если файл голоса не загрузился) `getDuration()` возвращает 0, и «Save» либо создаёт END с `time = 0`, либо переносит существующий END в 0 (`:3249–3251`), после чего `Song.songLengthMs` = 0 (`karaoke-app/.../model/Song.kt:2711–2722`). 4. **Панели не обновляются после правки полей текущего маркера.** Поля «Type/Time/Label/Note/Chord/String\|Lad» пишут через `v-model` прямо в объект маркера (template:308–358), а `currentMarker` — та же ссылка, что элемент `sourceMarkers` (2377).

# [#336] S1: полный доступ к стемам выдаётся по «скрытому жесту», который минтится публичным `POST /api… (BR-018)

Задача: устранение дефекта **BR-018** (S1) из полного аудита кода (#336).

## Что не так

** полный доступ к стемам выдаётся по «скрытому жесту», который минтится публичным `POST /api/public/events` без какой-либо аутентификации и без проверки права на песню. `authorized()` считает такой токен достаточным основанием для отдачи полных mp3; сам токен возвращается в JSON-ответе `meta`.

## Доказательство

**
  ```
  if (data["eventType"] == "clickToLink" && data["linkType"] == "songMeta") {
      val songId = (data["songId"] as? String)?.toLongOrNull()
      val field = data["linkName"] as? String
      val shiftKey = (data["shiftKey"] as? String)?.toBoolean() ?: false
  ```
  (`PublicApiController.kt:1037–1040`) и
  ```
  if (token != null && gestureUnlockService.validateToken(token, id)) return true
  ```
  (`PublicPlayerController.kt:104`, SHA `1977838a`). Логика жеста: `TARGET_FIELD = "key"`, `REQUIRED_CLICKS = 3`, `CLICK_WINDOW_MS = 1500` (`PlayerGestureUnlockService.kt:66–88, 168–171`), `clientId` приходит из тела запроса, т.е. не привязан ни к IP, ни к пользователю. Параметры рассылки видны в публичном `karaoke-public/src/services/tracking.js:51–59` (`eventType=clickToLink`, `linkType=songMeta`, `shiftKey`), так что «секретность» жеста — только обфускация.

## Путь достижимости

** аноним → `POST /api/public/events` с `eventType=clickToLink&linkType=songMeta&linkName=key&songId=<id>&shiftKey=true&clientId=<любой>` ×3 за 1,5 с → `PublicApiController.events` → `PlayerGestureUnlockService.registerClick` → `issueToken(songId)` → `meta` = полный токен (TTL 30 мин) → `GET /api/public/player/<id>/fileminus.mp3?token=<meta>` → `authorized()` = true → `stemResponse` → полный mp3 без оплаты/премиума/эфира. То же для `filevoice/filebass/filedrums` и `playerdata` (маркеры/текст).

## Предлагаемая поправка

** убрать выдачу полного токена из публичного beacon-эндпоинта либо проверять право (эфир/премиум/подписка/SKIP) в момент отдачи байт, а не только валидность токена; если жест нужен как owner-only — привязать его к административной identity и не возвращать токен для платного контента.

## Статическая (не БД) сущность: REASONS

Hardcoded массив в `HomeView.vue` (в `data()`, аналогично `TOP_AUTHORS` в
`AboutView.vue`):

| Поле | Тип | Пример |
|------|-----|--------|
| `icon` | String (emoji) | `💾` |
| `title` | String (2-4 слова) | `Избранное` |
| `text` | String (≤80 символов) | `Сохраняйте любимые песни, не теряйте` |

5 записей (см. `plan.md` Summary про замену пункта 5):
1. 💾 Избранное — «Сохраняйте любимые песни, не теряйте»
2. 📜 История — «Помним, что вы слушали на прошлой неделе»
3. 🎵 Плейлисты — «Создавайте свои подборки»
4. 🔔 Уведомления — «Узнавайте о новых песнях любимых исполнителей»
5. 🆓 Бесплатно — «Регистрация бесплатна, карта не нужна»

## Переиспользуемый механизм 1: определение «аноним/зарег.»

Источник: `composables/useAuth.js` → `{ isLoggedIn }` (уже используется в
`AboutView.vue` для того же самого: скрыть/показать CTA в зависимости от
статуса).

**Использование в фиче**: `computed: { showReasonsBlock() { return
!this.isLoggedIn } }` — блок целиком скрыт для зарегистрированных (FR-005,
US2).

---

## Переиспользуемый механизм 2: трекинг клика по CTA

Источник: `services/tracking.js` → `trackUi(subtype, detail)`, который шлёт
`POST /api/public/events` с `eventType='ui'`. Уже используется в этом же
файле (`HomeView.vue`) для трекинга смены темы (`trackUi('theme', ...)`
внутри `useDesign.js`) и в `router/index.js` для навигации.

**Использование в фиче**: `trackUi('navigate', 'reasons_block_cta')` при
клике на CTA (FR-007, US3). `link_name` содержит `reasons_block_cta` —
отличимо от прочих `navigate`-событий по `linkName`.

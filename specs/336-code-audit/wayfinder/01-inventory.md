## Question

Построить полную инвентаризацию кода Karaoke на зафиксированном SHA и нарезать её на порции аудита так, чтобы полнота охвата была доказуема.

Нужно:

1. Перечислить все файлы production- и test-кода (Kotlin, Vue/JS/TS, Python, SQL, Dockerfile/nginx/compose, shell-скрипты `deploy/` и `tools/`), исключив `archive/`, `node_modules/`, `.venv/`, `build/`, `dist/`, generated. Для каждого файла: путь, модуль, prod/test, число строк.
2. Предложить нарезку на порции по 2–4 тыс. строк (ориентир — 60–80 порций), не разрывая файл между порциями и по возможности сохраняя границы модулей/доменов; файлы >2 тыс. строк — отдельными порциями.
3. Сделать ведомость покрытия `файл → порция` (CSV + человекочитаемая сводка), где каждый файл ровно в одной порции; сумма строк порций = сумма строк инвентаризации.
4. Отметить, какие модули дают основной объём и какие порции дадут максимум риска (публичный периметр, деньги, данные, конкурентность).

Артефакты: `specs/336-code-audit/inventory.md`, `specs/336-code-audit/coverage-ledger.csv`. Ветку/коммиты не создавать; файлы в рабочем дереве, ссылка на них — в комментарии к тикету.

# Quickstart: Валидация строки «Временная ссылка» в таблице FREE vs PREMIUM

**Branch**: `169-share-link-in-premium-compare` | **Phase**: 1 | **Date**: 2026-08-11

> Ручная проверка в браузере. CI/runtime-тестов в проекте нет (см.
> `AGENTS.md` «Тесты»). Эта инструкция используется разработчиком
> в рамках self-review и для финальной валидации после деплоя на прод.

## Предусловия

1. `karaoke-public` собран и запущен локально:
   ```bash
   cd deploy
   bash do.sh build_start_public
   # или для разработки:
   cd karaoke-public && npm install && npm run dev
   ```
2. Три тестовых состояния:
   - **аноним** (без логина);
   - **free-зарегистрированный** (`user.effectivePremium = false`);
   - **премиум** (`user.effectivePremium = true`).
3. Браузер DevTools открыт (`F12`) → вкладка `Network` (для проверки
   отсутствия новых HTTP-запросов от таблицы) и `Console` (без ошибок).

## 1. Анонимный пользователь (FR-001, FR-002)

1. Открыть `/premium` **без логина**.
2. Под заголовком «Что вы получите за подписку» видна **таблица сравнения**.
3. Таблица содержит **ровно 12 строк** (было 11):
   - 11 существующих строк (Онлайн-плеер / Поиск / Демо-фрагменты /
     Полный доступ / Избранное / Свои плейлисты / Непрерывное / Скорость /
     Тональность / Минусовки / Чат).
   - **+ 12-я строка** «Временная ссылка на песню».
4. В 12-й строке:
   - Колонка **FREE**: ❌ + `aria-label="нет"`.
   - Колонка **PREMIUM**: ✅ + `aria-label="есть"`, ячейка в выделенной
     PREMIUM-колонке (фон / иконка 👑).

**Проверка**:

```bash
# Из корня репозитория:
grep -c "feature:" karaoke-public/src/views/PremiumView.vue \
  | sed -n '/const COMPARISON_ROWS/,/^]/p' \
  # или вручную: в <script setup> → должно быть 12 элементов массива
```

## 2. Free-зарегистрированный пользователь (US1.2)

1. Залогиниться как **free-юзер** (без активной подписки).
2. Перейти на `/premium` → таблица сравнения видна.
3. Та же 12-строчная таблица, 12-я строка = «Временная ссылка на песню»,
   FREE ❌, PREMIUM ✅.
4. Под таблицей — кнопка CTA «Оформить премиум-подписку» (уже было, не меняется).

**Проверка в DevTools**:

```bash
# Должен быть POST-запрос /api/public/events?eventType=ui&linkType=navigate&linkName=free_vs_premium_cta
# (трекинг уже реализован в 005-free-vs-premium, FR-008)
```

## 3. Премиум-пользователь (US2.1, FR-005)

1. Залогиниться как **премиум-юзер** (`user.effectivePremium = true`).
2. Перейти на `/premium`.
3. Под заголовком «Вы премиум-пользователь — спасибо!» виден блок
   **«Что вы получили»** (вместо таблицы сравнения).
4. Фраза в блоке содержит упоминание временной ссылки:
   > «… создание минусовок и чат с автором проекта, **создание временной
   > ссылки на песню (1 ч / 24 ч / 7 д, до 2 устройств одновременно)**.»

**Подсчёт символов фразы** (≤ 400 для уверенного рендера на 360px):

```bash
# Извлечь содержимое <p class="km-card-body"> внутри v-else-блока
sed -n '/<section v-else/,/<\/section>/p' karaoke-public/src/views/PremiumView.vue \
  | wc -c
# Должно быть ~1100-1400 (включая теги и пробелы).
```

## 4. Адаптивность (FR-007, SC-005)

| Viewport | Что должно быть видно |
|---|---|
| **1280px** (desktop) | Обычная 3-колоночная таблица: фича / FREE / PREMIUM. |
| **360-500px** (mobile) | Та же таблица, но **стопкой** (`:media max-width 500px`, см. `PremiumView.vue:437-470`): для каждой строки сверху вниз — название фичи → «FREE: ✅/❌/до 100» → «PREMIUM: ✅/❌/до 500». |

**Проверка**: Chrome DevTools → Toggle device toolbar → выбрать iPhone SE
(375×667). Скроллить таблицу до 12-й строки. Должна прочитаться как
«Временная ссылка на песню — FREE: ❌ — PREMIUM: ✅».

## 5. Никаких новых HTTP-запросов (NFR-001)

DevTools → Network → фильтр по `/api/public/`:

| Запрос | Когда | Должно ли появиться |
|---|---|---|
| `/api/public/events` | При клике на CTA | Уже был, не новый |
| `/api/public/account/subscription/tariffs?scope=SONG` | На странице (для `songTariff`) | Уже был, не новый |
| `/api/public/auth/me` | На странице (для `useAuth`) | Уже был, не новый |

**Только эти 3 запроса**. Никаких новых эндпоинтов от таблицы
`COMPARISON_ROWS` не должно инициироваться (массив inline, без fetcher'а).

```

**Должно быть 0 errors / 0 warnings** (отсутствие изменений в baseline —

См. `CONTRIBUTING.md`.

cd karaoke-public
npm run build
# Выход: dist/ с новой версией. Проверить что в HTML

```

## 8. Проверка на проде (после `deploy_public.sh`)

1. Открыть `https://sm-karaoke.ru/premium` в инкогнито-режиме.
2. Прокрутить до таблицы — **12 строк**, последняя = «Временная ссылка на
   песню».
3. Войти под тестовым премиум-аккаунтом → блок «Что вы получили»
   содержит фразу с упоминанием шар-ссылки.

## Сводный чек-лист

- [ ] **12 строк** в таблице (было 11). Проверено `grep` или визуально.
- [ ] 12-я строка: **FREE ❌, PREMIUM ✅** с aria-label.
- [ ] PREMIUM-колонка 12-й строки визуально выделена (фон / иконка 👑).
- [ ] Премиум-блок «Что вы получили» содержит упоминание временной ссылки
      с конкретикой (1 ч / 24 ч / 7 д, до 2 устройств).
- [ ] Адаптивно на 360px (iPhone SE) — стопка читается.
- [ ] **0 новых HTTP-запросов** от таблицы (DevTools Network).
- [ ] `npm run lint:check` — зелёный.
- [ ] `npm run build` — собирается без ошибок; `grep "Временная ссылка на песню" dist/` находит упоминание.

Если все 8 пунктов ✅ — фича полностью закрывает `169-share-link-in-premium-compare/spec.md`.

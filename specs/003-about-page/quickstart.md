# Quickstart: Валидация страницы «О проекте» (QW-9)

**Branch**: `003-about-page` | **Phase**: 1 | **Date**: 2026-07-25

Сценарий проверки «end-to-end» после того, как оставшиеся gap'ы (T0xx —
блок «Площадки», кнопка «Поделиться», правка `growth.md`) закрыты.
Часть пунктов (1-6) проверяет уже реализованную часть — не должна была
сломаться при доработке.

## Предусловия

- `karaoke-public` собран и запущен локально (`do.sh build_start_public` или
  `npm run dev` в `karaoke-public/`).
- Открыт в браузере (desktop + мобильный viewport через DevTools).

## 1. Маршрут и навигация (FR-001, FR-005)

- Перейти на `/` → в главном меню (`HomeView.vue`, `.km-nav-card`) есть
  ссылка «О проекте» → ведёт на `/about`.
- В футере (`App.vue`, `.km-global-footer`) есть ссылка «О проекте» → тоже
  ведёт на `/about`.
- Прямой заход на `/about` без предварительной авторизации — страница
  открывается (FR-008: без авторизации).

## 2. Контент (FR-002, US1, US2)

- Заголовок h1 «О проекте «Караоке на Своём Месте»» присутствует.
- Hero-блок явно говорит «Полная дискография. Не сборник хитов» +
  примеры (КИНО, Агата Кристи, Король и Шут).
- Секция «Какие песни» явно содержит фразу «Преимущественно русский рок».
- Топ-15 авторов отображается сеткой (15 карточек, каждая с именем и
  примечанием).
- Динамический список «И ещё N исполнителей» подгружается из
  `GET /api/public/authors` и не дублирует топ-15.
- **[NEW]** Блок «Площадки» — `<SocialLinks />` отображает иконки
  Sponsr/Dzen/VK/VK-видео/Telegram/Max, клик открывает соответствующую
  ссылку в новой вкладке.
- **[NEW]** Кнопка «Поделиться» — открывает меню из 5 пунктов (VK, Telegram,
  WhatsApp, Odnoklassniki, «Скопировать ссылку»); клик по соцсети открывает
  share-URL в новой вкладке; клик «Скопировать ссылку» кладёт `location.href`
  в буфер обмена (проверить `navigator.clipboard.readText()` в консоли или
  вставкой в адресную строку).

## 3. Статистика (FR-004)

- Секция «Коллекция» показывает 4 числа (загружены из
  `GET /api/public/stats`), не пустые/не `NaN`.

## 4. CTA (FR-002, Acceptance Scenario US1.2)

- Блок «Что дальше?» внизу: «Послушать демо» → `/zakroma`; «Открыть каталог»
  → `/zakroma`; «Зарегистрироваться» (если не залогинен) → `/register`;
  «В личный кабинет» (если залогинен) → `/account`.

## 5. Трекинг вовлечённости (FR-007, SC-002, SC-003, SC-004)

- Открыть DevTools → Network, отфильтровать `/api/public/events`.
- Проскроллить страницу до конца → видно запросы с `linkType=scroll`,
  `linkName=about:25|50|75|100` (по мере прохождения вех).
- Уйти со страницы (закрыть вкладку/перейти на другую) → должен уйти
  `eventType=engagement&page=about&linkName=<секунды>` (через
  `fetch(..., {keepalive: true})`, может не показаться в Network после
  ухода со страницы — проверить через `tbl_events` в БД, если есть доступ).

## 6. Адаптивность (FR-006, SC-006, NFR-003)

- 360px (мобильный): `.km-stats-grid`, `.km-top-grid`, `.km-cta-grid`
  схлопываются в 1 колонку (медиа-запрос `@media (max-width: 700px)`).
- 768px (планшет) и 1280px (десктоп): сетки многоколоночные, контент
  ограничен `max-width: 800px` и центрирован.

## 7. Производительность (NFR-001, SC-005)

- DevTools → Network → Throttling → «Slow 3G» → перезагрузить `/about` →
  время до интерактивности < 2 сек (два лёгких GET-запроса, без тяжёлых
  ассетов кроме логотипа).

## 8. Документация (растровая часть)

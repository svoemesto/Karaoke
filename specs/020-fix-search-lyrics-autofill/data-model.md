# Data Model: Исправление автоподстановки найденного текста песни

Схема БД не меняется. Ниже — сущности, участвующие в поведении, которое
исправляется, и уточнённый инвариант.

## Song (`tbl_songs`)

Поля, релевантные этой фиче (без изменений структуры):

| Поле | Тип | Описание |
|------|-----|----------|
| `source_text` | text | Текст песни. "Текста ещё нет" ⇔ значение равно `''` либо `'[""]'` (см. инвариант ниже). |
| `id_status` | bigint | Статус готовности песни. Автоподстановка применяется только при `id_status == 0`. |

**Инвариант (уточнён этой фичей)**: единственная точка истины для проверки
"есть ли у песни текст" — `Song.haveSourceText` (`sourceText != "" && sourceText != "[\"\"]"`).
Любой новый код, которому нужно решить "есть текст / нет текста", ДОЛЖЕН
использовать это свойство, а не собственную `isBlank()`/`isEmpty()` проверку
поля `sourceText`.

## SearchAsync (`tbl_search_async`)

Без изменений полей. Используется как запись о выполненном/выполняемом
запросе поиска для песни (один из 4 движков: `YANDEX_SYNC`, `YANDEX_ASYNC`,
`SEARXNG`, `FOURGET`). Поле `done` + `raw_data` определяют, готов ли результат
к разбору в `SearchResult`.

## SearchResult (`tbl_search_results`)

Без изменений полей. Кандидат текста песни (`text`) по конкретной найденной
ссылке (`url`), привязан к `SearchAsync` (`search_async_id`) и песне
(`song_id`). Пустой `text` (`""`) не участвует в подстановке.

## Логический поток (после исправления)

```
Поиск завершён (любой из 4 движков)
        │
        ▼
Кандидаты текста собраны как список SearchResult / текстовых строк
        │
        ▼
Есть хотя бы один непустой кандидат?  ──нет──▶  ничего не подставляем
        │ да
        ▼
!Song.haveSourceText (source_text == '' или '[""]') И id_status == 0?
        │ да                                          │ нет
        ▼                                              ▼
source_text = первый непустой кандидат        текст не перезаписывается
id_status = 1
saveToDb()
```

Эта логика теперь одинакова для всех 4 движков (см. `research.md`, Вопрос 2).

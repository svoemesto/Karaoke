# Guidelines

> **Статус**: в разработке. Каркас развёрнут в
> `322-knowledge-scaffold`. Наполнение ведётся в следующих
> спецификациях.

Стандартные паттерны и ограничения, действующие на весь проект.

## Планируемое наполнение

| Документ | Назначение | Источник |
| --- | --- | --- |
| `kdoc-jsdoc.md` | Правила KDoc/JSDoc и шаблоны | `docs/api/README.md` |
| `kotlin-style.md` | Kotlin style (ktlint baseline) | `CONTRIBUTING.md` |
| `vue-style.md` | Vue/Vite style | `CONTRIBUTING.md` |
| `runbooks/` | Операционные playbook'и | `livedocs/runbooks/` |
| `architecture/` | Архитектурные конвенции (nginx, docker, ml-pipeline и т.п.) | `livedocs/architecture/` |

## Связь с шаблонами

В отличие от `knowledge/templates/`, здесь лежат **руководства и паттерны**,
а не структурные шаблоны документов.

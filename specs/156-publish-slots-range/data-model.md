# Data Model: Расширение диапазона свободных слотов публикации

Новых таблиц, колонок или сохраняемых сущностей фича не вводит — она только меняет
логику *чтения* существующих данных `tbl_songs` и построения производного,
невыгружаемого в БД списка подсказок. Ниже — сущности, фигурирующие в вычислении
(в терминах кода, не БД-схемы).

## Часовой слот (Hour Slot)

Фиксированный час дня, для которого система предлагает одну дату публикации.

| Поле | Тип | Описание |
|------|-----|----------|
| `hour` | `Int` (10..22) | Целый час дня, 13 значений: 10, 11, …, 22 |
| `label` | `String` | Текстовое представление часа, `"HH:00"` (используется как значение `publish_time` в `tbl_songs` и как ключ группировки в SQL-запросе) |

**Источник существующих данных**: `tbl_songs.publish_time` (текстовая колонка формата
`HH:mm`) — используется для группировки и поиска `MAX(publish_date)` по каждому часу.

**Валидация**: список часов — константа в коде (10..22 включительно), не
пользовательский ввод; валидация не требуется.

## Свободный слот (Free Slot)

Результат вычисления для одного часового слота — конкретная будущая дата+время,
предлагаемая пользователю.

| Поле | Тип | Описание |
|------|-----|----------|
| `hour` | Часовой слот (см. выше) | К какому часу относится |
| `lastUsedDate` | `LocalDate?` | Самая поздняя дата (`tbl_songs.publish_date`, распарсенная), уже занятая публикацией в этот час; `null`, если час никогда не использовался |
| `candidateDateTime` | `LocalDateTime` | Итоговая предложенная дата+время — вычисляется по правилу из `research.md` (Вопрос 2); инвариант: **всегда** строго позже момента вычисления (`LocalDateTime.now()` на сервере) |

**Инвариант (FR-004)**: `candidateDateTime > now()` в момент вычисления — для
**каждого** элемента результирующего списка, без исключений.

**Формат вывода** (не меняется, существующий контракт эндпоинта): `String` вида
`dd.MM.yy HH:mm` (например, `08.08.26 10:00`).

## Отношения

```text
tbl_songs (существующая таблица, читается только)
  publish_date: text "DD.MM.YY"
  publish_time: text "HH:mm"
       │
       │ GROUP BY publish_time, MAX(TO_DATE(publish_date, 'DD.MM.YY'))
       ▼
Map<Часовой слот, lastUsedDate?>  (промежуточное состояние в памяти, не персистится)
       │
       │ для каждого из 13 часовых слотов (10..22), включая отсутствующие в Map
       ▼
List<Свободный слот>  →  форматируется в List<String> → ответ эндпоинта getfreetimeslots
```

## Изменения существующих сущностей

Никакие существующие сущности (`Song`, `tbl_songs` схема) не меняются — фича не
добавляет и не удаляет колонки, не меняет DDL, не участвует в `SyncRegistry`
(Principle III конституции не затрагивается).

# Отчёт: #199 — дубликат id="app" в DOM

**PR:** #608, ветка `516-fix-dup-app-id`. **Severity:** S3.

## Причина

`index.html` содержит `<div id="app">` — точку монтирования Vue
(`app.mount('#app')`). `App.vue` рисовал **внутри** неё ещё один
`<div id="app">`. Правило `#app` живёт в **не-scoped** блоке `<style>` файла
`App.vue`, поэтому применялось к обоим элементам: два вложенных flex-контейнера
высотой 100vh.

## Проверка

| | до | после |
|---|---|---|
| `document.querySelectorAll('#app').length` | **2** | **1** |
| вычисленные стили обоих | `display:flex; flex-direction:column; height:100vh` | стилизуется один |

Снимок `/songs` до и после — попиксельно совпадает: правка структурная.
Регрессия закреплена тестом в `e2e/smoke.spec.js`. Полный набор 14/14.

## Побочная находка, оставленная на потом

В `src/style.css:61` есть второе правило `#app` (max-width/padding), которое в
собранный CSS не попадает — в `dist/assets/index-*.css` ровно одно правило
`#app`, из `App.vue`. Правило мёртвое; не трогал в этом тикете.

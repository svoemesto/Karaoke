## `GET /api/public/account/history`

**Назначение**: список последних прослушанных песен текущего пользователя.

**Аутентификация**: обязательна. Тот же `SiteAuthInterceptor`, что и остальные
`/api/public/account/*` эндпоинты (`PublicPlaylistController.kt`) — запрос без
валидной сессии получает `401`/аналогичную ошибку интерцептора (существующее
поведение, эта фича его не меняет).

**Query-параметры**: нет обязательных. Опционально можно предусмотреть `limit`
(по умолчанию 100, максимум — на усмотрение реализации, но не более разумного
предела, см. FR-004 `spec.md`).

**Response 200**:

```json
{
  "items": [
    {
      "songId": 12345,
      "songName": "Группа крови",
      "songAuthor": "КИНО",
      "songAlbum": "Группа крови",
      "lastPlayed": "2026-07-24T18:30:00",
      "playCount": 3
    }
  ]
}
```

- `items` — массив, отсортирован по `lastPlayed` DESC.
- `items = []` — валидный ответ (пустая история, US2 в `spec.md`), не ошибка.

**Response при отсутствии/невалидной сессии**: стандартное поведение
`SiteAuthInterceptor` (как у остальных `/api/public/account/*` эндпоинтов) —
эта фича не вводит собственную обработку auth-ошибок.

**Побочные эффекты**: нет — чистый read-only запрос, ничего не пишет в БД.

**Идемпотентность**: да, полностью (GET, без побочных эффектов).

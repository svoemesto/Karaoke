# Quickstart: проверка синхронизации временных ссылок

## Предварительные условия

- Локальный PostgreSQL и доступный серверный PostgreSQL с таблицей `tbl_song_share_links` и `recordhash`-триггером.
- Доступ к admin UI и актуальным настройкам sync properties.
- Существующие связанные пользователь и песня на обеих сторонах.

## Статическая проверка

Из корня репозитория выполнить:

```bash
./gradlew ktlintCheck
./gradlew :karaoke-app:compileKotlin
```

Ожидаемый результат: проверки завершаются без новых ошибок.

## Сценарий 1: server → local по умолчанию

1. Создать или изменить временную ссылку только на серверной БД.
2. Открыть экран «Синхронизация».
3. Убедиться, что строка «Временные ссылки» присутствует, а направление one-click указано как сервер → локал.
4. Запустить «Синхронизация в 1 клик».
5. Проверить, что на локали появился тот же `id`, владелец, song id, срок действия и состояние активности; token-related поля не отображаются в результате.
6. Повторить запуск и убедиться, что дублей и новых изменений нет.

## Сценарий 2: изменение и отзыв

1. Изменить срок действия или статус отзыва на сервере.
2. Выполнить one-click pull.
3. Проверить совпадение изменённых nullable-полей и `recordhash` на обеих сторонах.
4. Проверить summary: изменённая запись указана, а секретные значения не раскрыты.

## Сценарий 3: явный local → server

1. Временно включить необходимые push operation flags для `sharelinks`.
2. Создать или изменить ссылку на локали.
3. Явно запустить entity sync с направлением local → server.
4. Проверить запись на сервере и отсутствие дубликата.
5. Вернуть operation flags в безопасное состояние после проверки.

## Сценарий 4: ошибка соединения

1. Запустить sync при недоступной одной из БД.
2. Убедиться, что UI показывает ошибку для временных ссылок и не сообщает об успешном переносе.
3. После восстановления соединения повторить операцию и проверить идемпотентный результат.

Полный формат данных и ограничения полей описаны в [data-model.md](data-model.md), интерфейс — в [contracts/sync-temporary-links.md](contracts/sync-temporary-links.md).

# Quickstart: Корректный прогресс загрузки песен при открытии альбома автора

**Feature**: [spec.md](./spec.md) | **Branch**: `444-fix-album-progress` | **Issue**: #179

> Проверка фикса end-to-end после деплоя (сборку/рестарт делает владелец).

## Prerequisites

1. Контейнеры `karaoke-public` и `karaoke-web` обновлены (сборка — владельцем):
   ```bash
   cd deploy && bash do.sh build_public && bash do.sh build_web
   ```
2. Браузер с DevTools.

## Сценарий 1 — Главный кейс (issue #179)

1. Открыть `/zakroma`, выбрать автора с большим числом песен (например, «Машина Времени», 2485).
2. Перейти на `/zakroma/{authorId}/albums`.
3. Запомнить число песен на плашке небольшого альбома (например, 10).
4. Кликнуть плашку альбома.

**Ожидаемо:**
- URL `/zakroma/{authorId}?albumId={id}`.
- Прогресс: «Загружаем X из 10 песен автора «Машина Времени»…» (знаменатель = число на плашке, НЕ 2485).
- Полоса доезжает до 100%.

## Сценарий 2 — Гость vs редактор

1. Как гость (инкогнито): знаменатель = «N готовых» с плашки.
2. Залогиниться редактором: знаменатель = «N песен» с плашки.

## Сценарий 3 — Регресс: все песни автора

1. Открыть псевдо-плашку «Все песни автора с группировкой по альбомам» (`/zakroma/{authorId}` без `?albumId=`).
2. Прогресс: «Загружаем X из 2485 песен автора…» (по автору, как раньше).

## Сценарий 4 — Deep-link

1. В новой вкладке вставить `/zakroma/{authorId}?albumId={id}` напрямую.
2. Знаменатель — по альбому (не 0, не автор).

## Сценарий 5 — Несуществующий альбом

1. `/zakroma/{authorId}?albumId=999999`.
2. Страница пустая/без песен, прогресс-знаменатель 0 (не число песен автора).

## API-проверка (curl)

```bash
curl -sN 'http://localhost:8897/api/public/zakroma/stream?author=Машина%20Времени&albumId=<id>' | head -1
# {"type":"meta","author":"Машина Времени","expectedCount":<число песен альбома>}
```

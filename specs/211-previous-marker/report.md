# Отчёт: #211 — «[» перескакивала через маркер слева от указателя

**Work package:** #211
**PR:** #599, коммит `dbe66ebc`

## Симптом

Нажатие «[» («предыдущий маркер») с позиции **между** двумя маркерами уводило
не на маркер слева, а через один. Владелец замечал это в работе с редактором.

## Причина

`goToPreviousMarker` стартовал поиск с `currentMarkersIndex = -1` и пропускал
маркеры, у которых `currentMarker.time >= currentTime - diff`. При позиции между
маркерами указатель оказывался на первом маркере, а цикл, начиная с минуса
единицы и пропуская «уже пройденные», приходил к следующему за указателем.

## Исправление

Старт с `currentMarkersIndex` (то есть с маркера, на котором стоит указатель),
а не с минуса единицы. Логика пропуска не менялась.

## Закрепление регрессии

Три e2e-теста в `e2e/marker-nav.spec.js` покрывают раздельно:

1. «[» с позиции **между** маркерами идёт на маркер слева, а не через один.
2. «]» с той же позиции идёт на правый маркер — **контроль**: правка не задела
   вперёд.
3. «[» с позиции **ровно на** маркере ведёт на один назад, а не на тот же.

Второй тест — контрольный: он ломается, если исправление слишком широкое.
Все три входят в общий набор (13/13 зелёные).

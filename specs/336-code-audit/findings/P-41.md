## Находки

### P-41-01: karaoke-db/gradle/wrapper/gradle-wrapper.properties:3 — BUILD (S3)
- Что не так: модуль `karaoke-db` закреплён на Gradle **7.5.1** (дистрибутив 2023 года), тогда как `karaoke-app` и `karaoke-web` используют **9.1.0**, а корневой wrapper — 8.14. Разнобой версий в одном репозитории: сборка модуля тянет старый дистрибутив Gradle (отдельный кэш `GRADLE_USER_HOME/wrapper/dists`), а версия 7.5.1 не понимает современные возможности (например, toolchain-плагин для Java 21, который используют соседние модули) и содержит известные уязвимости ветки 7.x.
- Доказательство:
  ```
  distributionUrl=https\://services.gradle.org/distributions/gradle-7.5.1-bin.zip
  ```
  (`karaoke-db/gradle/wrapper/gradle-wrapper.properties:3`, SHA 1977838a). Контраст: `karaoke-app/gradle/wrapper/gradle-wrapper.properties:3` — `gradle-9.1.0-bin.zip`, `karaoke-web/...` — `gradle-9.1.0-bin.zip`, корневой `gradle/wrapper/gradle-wrapper.properties:3` — `gradle-8.14-bin.zip`.
- Путь: любой запуск `./gradlew` в `karaoke-db` (или IDE) скачивает и использует Gradle 7.5.1 → расхождение с остальным репозиторием, риск воспроизводимости сборки и известные CVE ветки 7.x.
- Поправка: выровнять версию wrapper'а на используемую в `karaoke-app`/`karaoke-web` (9.1.0) либо убрать модуль `karaoke-db` целиком (см. «Сверки»).

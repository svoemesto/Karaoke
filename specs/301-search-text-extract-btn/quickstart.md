# Quickstart: Кнопка «Получить текст по ссылке» — обновление UI без закрытия модалки

**Связанная спека**: [spec.md](spec.md)
**Связанное research**: [research.md](research.md)

Этот документ — **runnable validation guide** для ручной проверки фикса OP#51.

## Prerequisites

1. **Машина**: dev-машина с поднятым `karaoke-app` + `webvue3` (см. `docs/onboarding.md`).
2. **Доступ к admin SPA**: `https://localhost:8897/`.
3. **Тестовая песня**: в БД должна быть песня с заполненными метаданными (автор, название), чтобы поиск находил результаты. После прошлых поисков должны быть «серые» результаты (без `text`).
4. **Git-ветка**: `301-search-text-extract-btn` (эта ветка содержит фикс).

## Validation scenarios

### Scenario 1: Главный сценарий OP#51 — текст появляется сразу

**Цель**: подтвердить, что после нажатия «Получить текст по ссылке» textarea показывает текст, а пункт перестаёт быть серым — **без закрытия модалки**.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|-------------------|
| 1.1 | Открыть песню в `SongEdit.vue`, нажать кнопку «Поиск текста в интернете» (значок `icon_search_text.svg`) | Открывается модалка «Поиск текста песни в интернете» |
| 1.2 | Дождаться завершения поиска | В левом столбце — список результатов, у некоторых `text === ''` (серые) |
| 1.3 | **Кликнуть на «серый» результат** | Результат подсвечивается синим (`blue`), в правом столбце появляется URL |
| 1.4 | В правом столбце видны **обе кнопки, столбиком** | Сверху «Открыть на сайте», ниже — «Получить текст по ссылке» |
| 1.5 | Нажать «Получить текст по ссылке» | Кнопка disabled, текст меняется на «Получаю текст...», через ~3-15 сек ответ |
| 1.6 | После прихода ответа | **textarea справа содержит полученный текст** (главный критерий!), выбранный пункт в списке **перестал быть серым** (стал белым, или остался синим — зависит от того, был ли клик) |
| 1.7 | **Модалка остаётся открытой** | Админ видит результат без переоткрытия |

### Scenario 2: Расположение кнопок

**Цель**: подтвердить визуальное расположение кнопок «Открыть на сайте» и «Получить текст по ссылке» столбиком.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|-------------------|
| 2.1 | Открыть модалку, выбрать «серый» результат | Обе кнопки видны в правом столбце |
| 2.2 | Визуально проверить | Кнопки одинаковой ширины, столбиком (одна под другой), без горизонтального смещения |

### Scenario 3: Регрессия — кнопка скрыта при уже полученном тексте

**Цель**: убедиться, что поведение `v-if` сохранено.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|-------------------|
| 3.1 | Выбрать результат с уже заполненным `text` | Кнопка «Получить текст по ссылке» **скрыта** (`canExtractLyrics === false`) |
| 3.2 | Визуально | Видна только «Открыть на сайте» |

### Scenario 4: Регрессия — кнопки в нижней панели модалки (footer)

**Цель**: убедиться, что добавление `display: block` в `.group-button` не сломало кнопки в `.st-footer` (lines 56-89 — «Искать заново», «Удалить результаты поиска»).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|-------------------|
| 4.1 | Открыть модалку | В нижней панели видны кнопки «Искать заново», «Удалить результаты поиска» |
| 4.2 | Визуально | Кнопки видимы и кликабельны, расположение не сломано (если были столбиком — остались столбиком, если в строку — остались в строку) |

### Scenario 5: Регрессия — открытие ссылки работает

| Шаг | Действие | Ожидаемый результат |
|-----|----------|-------------------|
| 5.1 | Выбрать любой результат | — |
| 5.2 | Нажать «Открыть на сайте» | Открывается новая вкладка с URL результата |

### Scenario 6: Регрессия — кнопка disabled во время запроса

| Шаг | Действие | Ожидаемый результат |
|-----|----------|-------------------|
| 6.1 | Нажать «Получить текст по ссылке» | Кнопка disabled, текст «Получаю текст...» |
| 6.2 | Попытаться кликнуть ещё раз | Ничего не происходит (функция возвращается на guard `if (this.isExtractingLyrics) return`) |

### Scenario 7: Edge case — ошибка backend

**Цель**: убедиться, что при ошибке извлечения показывается `alert`, и UI не ломается.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|-------------------|
| 7.1 | Выбрать серый результат, нажать «Получить текст по ссылке» | Если backend возвращает `lastError`, показывается `window.alert` |
| 7.2 | После alert | UI остаётся в исходном состоянии (textarea пустая, пункт остаётся серым, кнопка снова enabled) |

## Expected outcomes (definition of done)

Все 7 сценариев проходят:

- ✅ **SC-001** (Scenario 1): textarea показывает полученный текст, пункт перестаёт быть серым, модалка остаётся открытой.
- ✅ **SC-002** (Scenario 2): кнопки визуально столбиком в одном контейнере.
- ✅ **SC-003** (Scenarios 3-6): 0 регрессий в существующем поведении (скрытие кнопки, кнопки в footer, открытие ссылки, disabled).
- ✅ **SC-004** (Scenario 7): ошибка обрабатывается корректно.

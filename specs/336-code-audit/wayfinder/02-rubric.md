## Question

Утвердить рубрику аудита — контракт, по которому субагенты относят находку в список или отбрасывают.

Черновик готовит лид, владелец утверждает. В черновике:

- определение дефекта и граница «дефект vs задумано vs косметика»;
- классы находок (например: SEC — доступ/инъекции; DATA — потеря/порча данных; RACE — конкурентность; LEAK — ресурсы/память/соединения; ERR — обработка ошибок и исключений; PERF — деградация; COMPAT — контракты API/БД; RULE — нарушение MUST/архитектурного правила; TEST — дефект теста);
- семантика S1–S3 и правило «тест — не выше S3»;
- какие источники правил обязательны (конституция, AGENTS.md MUST, architecture-conventions.md R-04…R-44, code-style.md, инварианты доменов knowledge/);
- что не попадает в основной список (косметика, уже известные baseline-нарушения, вкусовщина);
- как оформляется «Требует решения владельца».

Результат: `specs/336-code-audit/rubric.md`, утверждённый владельцем. Без утверждения массовый аудит не стартует.

## 2. UI-структура: `COMPARISON_ROW` (JavaScript inline)

Файл: `karaoke-public/src/views/PremiumView.vue:204-220`.

```js
/**
 * @typedef {Object} ComparisonRow
 * @property {string} feature                   // Заголовок строки в колонке «Фича».
 * @property {boolean|string} free              // Значение в колонке FREE.
 * @property {boolean|string} premium           // Значение в колонке PREMIUM.
 *
 * Правила значений:
 *   - boolean: true  → рендерится «✅»,
 *               false → рендерится «❌»
 *     (рендер — `PremiumView.vue:35-46` через `:aria-label` для a11y).
 *   - string: рендерится буквально как текст в ячейке
 *     (например, «до 100», «до 500», «1 (избранное)», «до 50»).
 */
const COMPARISON_ROWS = [
  // ... существующие 11 строк ...
  { feature: 'Временная ссылка на песню', free: false, premium: true },  // ← НОВАЯ 12-я
]
```

### 2.1. Валидация (linter)

ESLint в `karaoke-public/` (`npm run lint:check`) валидирует:

- Что каждый объект имеет все 3 свойства (`feature`, `free`, `premium`).
- Что `feature` — непустая строка (защита от «случайно стёрли»).
- Что строки единообразно отформатированы (single quotes, без trailing
  commas — стиль проекта, см. `CONTRIBUTING.md`).

### 2.2. Инварианты

1. **Порядок**: новая строка добавляется в **конец** массива — чтобы не
   сбивать нумерацию и согласование с `005-free-vs-premium/spec.md FR-003`
   (см. `spec.md/FR-006`).
2. **Длина префикса строки**: ≤ 60 символов (визуально умещается на
   мобильном 360px). Проверяется визуально; сейчас все строки ≤ 50.
3. **FREE/PREMIUM в одной строке** — не могут оба быть `false` (бессмысленно).
4. **FREE строго меньше или равно PREMIUM** (логика: free — это «ограничение»,
   premium — это «полный доступ», концептуально фича не отбирается, только
   расширяется).

### 2.3. State Transitions

N/A — массив `COMPARISON_ROWS` immutable на всё время сессии. Не
мутируется по ходу жизни компонента.

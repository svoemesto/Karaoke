- **BR-код**: BR-124

## Что проверял

Утверждения находки P-61-08:

1. Обработчики кнопок «Опубликовать во ВК (air)/(premium)» вызывают `this.$store.dispatch('promisedXMLHttpRequest', request)`,
   но такого action нет ни в одном модуле стора (`actions: {}` в корне, в `Songs/store.js`
   `promisedXMLHttpRequest` — импортированная функция из `lib/utils`).
2. Симптом: клик → `TypeError` в обработчике → запрос не уходит, состояние «Публикация…» зависает.
3. `id` брался из `state.currentSongId`, которого нет (модуль стора живёт под ключом `song`).

Требования задачи (критерии готовности): `npm run lint:check` — зелёный, `npm run test:unit` —
зелёный, добавлен юнит-тест на исправленное поведение, изменения закоммичены.

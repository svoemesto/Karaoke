# Quickstart: Список авторов в фильтрах

**Feature**: `450-author-filter-datalist` | **Date**: 2026-09-24

Руководство по ручной проверке фичи end-to-end. Детали поведения — в
[contracts/ui-author-datalist.md](contracts/ui-author-datalist.md) и
[data-model.md](data-model.md); реализация — в `tasks.md`.

## Предусловия

- Ветка `450-author-filter-datalist` активна.
- Доступна работающая admin-сборка `webvue3` (backend с endpoint
  `POST /api/songs/authors` и непустым справочником авторов).
- Node 22 LTS установлен.

## Сборка и линт (обязательно перед ручной проверкой)

```bash
cd webvue3
npm run lint
npm run build
npm run format:check
```

Ожидание: все три команды завершаются успешно (нет новых ошибок сверх
baseline).

## Запуск dev-сервера

```bash
cd webvue3
npm run dev
```

Открыть админку в браузере, авторизоваться.

## Сценарий 1 — «Авторы» (US1, P1)

1. Открыть раздел **Авторы**.
2. Нажать кнопку «Фильтр» → открывается модалка «Фильтр для настроек».
3. Кликнуть в поле **«Автор:»**, начать вводить 2–3 буквы известного автора.

**Ожидание**: появляется выпадающий список имён авторов, отфильтрованный по
введённой подстроке.

4. Выбрать автора из списка.
5. Нажать **«Применить фильтр»**.

**Ожидание**: подставилось точное имя; таблица показывает записи только
этого автора.

6. Очистить поле (кнопка «X») и применить фильтр.

**Ожидание**: показываются все записи (поведение не изменилось).

## Сценарий 2 — «Альбомы» (US2, P2)

1. Открыть раздел **Альбомы**.
2. Нажать «Фильтр» → модалка «Фильтр для альбомов».
3. Кликнуть в поле **«Автор:»** и начать вводить имя.

**Ожидание**: появляется такой же список подсказок авторов, как в Сценарии 1.

4. Выбрать автора → **«Применить фильтр»**.

**Ожидание**: показываются альбомы этого автора.

## Сценарий 3 — единообразие (US3, P3)

1. По очереди открыть фильтры **Песни**, **Авторы**, **Альбомы**.
2. Сравнить список подсказок в поле «Автор:».

**Ожидание**: набор подсказок идентичен во всех трёх (один источник —
`/api/songs/authors`).

## Сценарий 4 — устойчивость (Edge cases)

1. **Сеть**: заблокировать/симулировать отказ `POST /api/songs/authors`,
   открыть фильтры «Авторы» и «Альбомы».
   **Ожидание**: модалки открываются, поле «Автор:» работает как обычный
   текстовый ввод, ошибок в UI нет.
2. **Сохранённый фильтр**: применить фильтр по автору, обновить страницу
   (F5), снова открыть модалку.
   **Ожидание**: сохранённое имя подставлено; справочник его не стёр.
3. **Большой список**: убедиться, что при сотнях авторов ввод не «лагает».

# Implementation Plan: Audio Transpose for Premium Users

**Branch**: `095-transpose-audio` | **Date**: 2026-07-30 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/095-transpose-audio/spec.md`

## Summary

Implement real-time audio transposition (+/-6 semitones) for premium users in the online player (`karaoke-public`). The feature allows users to change the playback key on the fly without reloading the page or persisting transposed stems. Free users see a premium upsell prompt. The primary technical approach is client-side pitch shifting via Web Audio API, with a documented server-side fallback path using ffmpeg streaming if client-side performance proves insufficient on mobile.

## Technical Context

**Language/Version**: Kotlin 1.x (backend), Vue 3 + TypeScript (frontend), Node 22

**Primary Dependencies**: Spring Boot (karaoke-web), ffmpeg (existing pipeline), Web Audio API (browser native)

**Storage**: PostgreSQL (user session/preferences), MinIO (original stems, unchanged)

**Testing**: Manual validation via browser DevTools + audio analysis. No automated test suite in CI per project convention.

**Target Platform**: Web (modern desktop and mobile browsers: Chrome, Firefox, Safari, Edge)

**Project Type**: Web application — public SPA (`karaoke-public`) consuming API from `karaoke-web`

**Performance Goals**: Audio key change audible within 2 seconds; gapless switching (<1.5s gap) for 95% of interactions

**Constraints**:
- MUST NOT permanently store transposed stems in MinIO (spec requirement)
- MUST reuse existing premium check mechanism
- MUST work within existing dual-frontend architecture (`karaoke-public` vs `webvue3`)
- MUST comply with Constitution Principle I (self-contained pipeline) — avoid external SaaS for audio processing
- ProcessBuilder `redirectErrorStream(true)` if any server-side ffmpeg used

**Scale/Scope**: Single feature in public player; affects ~5k monthly visitors, premium subset (~3 users/month currently per growth baseline). Designed to scale with premium growth.

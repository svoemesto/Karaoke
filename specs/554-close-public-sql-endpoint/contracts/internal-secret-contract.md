# Contract: внутренний секрет синхронизации (`X-Internal-Secret`)

**Версия**: 1.0 · **Дата**: 2026-10-24 · **Ветка**: `554-close-public-sql-endpoint`

Контракт между двумя сторонами:

- **Отправитель** — `karaoke-app` (служба двуx-БД синхронизации) на админской машине;
- **Получатель** — `karaoke-web`, эндпоинт `POST /changerecords`.

## Транспорт

| Свойство | Значение |
|---|---|
| URL | `POST https://sm-karaoke.ru/changerecords` (публичное имя, доступ ограничен сетевым фильтром) |
| Тело | `application/json`, существующий формат без изменений |
| Заголовок авторизации | `X-Internal-Secret: <значение>` |
| Сравнение | точное, регистрозависимое, по всему значению |

## Правила приёма (получатель)

1. Если секрет **не настроен** (пустое значение) → **403**, ничего не выполняется.
2. Если заголовок отсутствует → **403**.
3. Если заголовок присутствует, но не совпадает с настроенным секретом → **403**.
4. Если заголовок совпадает → запрос обрабатывается как раньше.

## Правила отправки (отправитель)

1. Заголовок `X-Internal-Secret` добавляется к каждому запросу.
2. Ответ **403** — это отказ по правам, а не сетевая ошибка: повтор не выполняется.
3. Сетевые ошибки (таймаут, сброс, TLS) — по текущему правилу: одна повторная попытка.

## Ответы

| Код | Когда | Тело |
|---|---|---|
| 200 | действия применены | текущий ответ сервиса (без изменений) |
| 403 | нет/неверный секрет либо секрет не настроен | короткий текст без деталей; **без** текста ошибки БД |
| 5xx | внутренняя ошибка обработки | текст ошибки БД **не** возвращается наружу |

## Журналирование

Категория `infra.sync.security`, сообщение `sync:security:denied`, уровень WARN, поля:
время, адрес источника, причина (`missing_secret` / `invalid_secret` / `secret_not_configured`).
Тело запроса и текст ошибки БД не пишутся.

## Обе стороны должны использовать одно значение

Значение задаётся один раз и вводится в двух местах:
- `karaoke-web` — переменная окружения `SYNC_INTERNAL_SECRET` (через `application.yml` → `sync.internal-secret`);
- `karaoke-app` — свойство `syncInternalSecret` в `Karaoke.properties`.

Значение не коммитится и не попадает в репозиторий, сборку и журналы.

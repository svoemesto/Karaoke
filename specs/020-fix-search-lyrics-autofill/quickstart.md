# Quickstart: проверка исправления автоподстановки текста песни

Ручная проверка (в CI нет надёжных тестов для этого пайплайна — см.
`research.md`, Вопрос 4). Выполняется на LOCAL-окружении админки.

## Предусловия

- Поднят локальный стек (`karaoke-app`, БД) — см. `deploy/do.sh`.
- Есть тестовая песня (любая, лучше с "мусорным" автором/названием, чтобы
  поиск не тратился на что-то ценное) с известным `id`.
- Доступен хотя бы один рабочий движок поиска текста (`SEARXNG`/`FOURGET`
  самостоятельно развёрнуты локально; `YANDEX_SYNC`/`YANDEX_ASYNC` требуют
  валидный IAM/folderId в `Karaoke.properties`).

## Сценарий 1 — `source_text = '[""]'`, движок SEARXNG/FOURGET

1. Выставить тестовой песне `source_text = '[""]'`, `id_status = 0`:
   ```sql
   UPDATE tbl_songs SET source_text = '[""]', id_status = 0 WHERE id = <ID>;
   ```
2. В webvue3 → «Песни» → выбрать эту песню → «Найти текст песни» →
   движок `SEARXNG` (или `FOURGET`) → подтвердить.
3. **Ожидаемый результат**: если поиск нашёл непустой текст-кандидат —
   `source_text` песни в БД/UI заполнен найденным текстом, `id_status = 1`.
   (До исправления: `source_text` оставался `'[""]'` несмотря на найденный
   текст.)

## Сценарий 2 — `source_text = ''`, тот же движок (регресс существующего поведения)

1. `UPDATE tbl_songs SET source_text = '', id_status = 0 WHERE id = <ID>;`
2. Повторить поиск как в Сценарии 1.
3. **Ожидаемый результат**: поведение идентично Сценарию 1 (это уже работало
   до исправления — важно не сломать).

## Сценарий 3 — движок YANDEX_SYNC

1. `UPDATE tbl_songs SET source_text = '[""]', id_status = 0 WHERE id = <ID>;`
2. Запустить поиск с движком `YANDEX_SYNC` (single-song или через «Найти
   тексты для всех песен» с выбором этого движка).
3. **Ожидаемый результат**: при найденном непустом тексте-кандидате —
   `source_text` заполняется, `id_status = 1`, так же как в Сценариях 1-2.
   (До исправления: подстановки не было вообще ни при `''`, ни при `'[""]'`.)

## Сценарий 4 — уже есть реальный текст (не должно перезаписываться)

1. `UPDATE tbl_songs SET source_text = 'Реальный текст песни', id_status = 0 WHERE id = <ID>;`
2. Запустить поиск любым движком, дождаться завершения.
3. **Ожидаемый результат**: `source_text` остаётся `'Реальный текст песни'`
   без изменений.

## Сценарий 5 — пакетный запуск «Найти тексты для всех песен»

1. Подготовить 2+ тестовые песни: одну с `source_text = ''`, другую с
   `source_text = '[""]'`, обе `id_status = 0`.
2. В webvue3 → «Песни» → выделить обе → «Найти тексты для всех песен» →
   выбрать движок → подтвердить.
3. **Ожидаемый результат**: у обеих песен (при найденных непустых
   кандидатах) текст подставился одинаково, независимо от исходного
   представления "пустого" значения.

## Откат тестовых данных

```sql
UPDATE tbl_songs SET source_text = '', id_status = 0 WHERE id IN (<ID1>, <ID2>);
DELETE FROM tbl_search_results WHERE song_id IN (<ID1>, <ID2>);
DELETE FROM tbl_search_async WHERE song_id IN (<ID1>, <ID2>);
```
